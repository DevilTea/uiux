title: Handoff bundle
summary: "The read-only bundle that downstream implementers consume: the root
  manifest and its identity, roots, resource snapshots, artifact, Evidence and
  implementation-source references, provenance including Adapter provenance, and
  machine-readable readiness, coverage and diagnostics."
clauses:
  - id: 01a115cd-d5d1-78dd-8d31-2eb0beb5dff7
    statement: The root manifest is a JSON object `{ schemaVersion, bundleIdentity,
      exportedAt, roots, resources, artifactRefs, evidenceRefs,
      implementationReferences, provenance, readiness }`, where `schemaVersion`
      is the manifest schema version, currently 1, and `exportedAt` an RFC 3339
      UTC timestamp.
  - id: 01a115cd-d60a-794c-8230-5ef65c6fc047
    statement: "`bundleIdentity` is the `sha256:` identity of the canonical JSON of
      the manifest without `exportedAt` and `bundleIdentity`, and an export
      stores the canonical manifest bytes as an artifact."
  - id: 01a115cd-d644-7e05-8f01-af40349c86c0
    statement: '`roots` is a non-empty list of distinct typed roots, `{ type:
      "workspace" }`, `{ type: "view", viewId }`, `{ type: "flow", flowId }` or
      `{ type: "asset", assetId }` with full UUIDs; no other root type exists.'
  - id: 01a115cd-d67e-701b-af7d-c0dbbc4733cf
    statement: Each `resources` entry is `{ type, identity, revision, snapshot,
      contentDigest? }`, holding a closure resource's canonical content and
      export-time revision; an Asset entry's `snapshot` is its `asset.json`, and
      its `contentDigest` the source content's `sha256:` identity.
  - id: 01a115cd-d6b8-7f80-bd03-34b85ec0152e
    statement: Each `artifactRefs` entry is `{ kind, artifact, context? }`, naming a
      distinct `sha256:` artifact with its kind and the context needed to
      interpret it.
  - id: 01a115cd-d6f2-76a9-a339-27e18374b7db
    statement: Each `evidenceRefs` entry is an Evidence reference `{ kind, evidence
      }` to an Evidence record included in the bundle.
  - id: 01a115cd-d72b-7c10-824a-8fd5fa625f9f
    statement: Each `implementationReferences` entry names one used Widget type as
      `widgetType`, with `semanticSource`, `rendererSource` and optional
      `designSystemSource` and `supportingSources`.
  - id: 01a115cd-d776-7b2e-ab7a-4199f7e4695f
    statement: A source reference is `{ availability, provenance, contentDigest? }`
      with `availability` `materialized`, `provenance-only` or `unavailable` and
      a non-empty `provenance`; a materialized source names its package or
      repository, revision and path and carries its `contentDigest`.
  - id: 01a115cd-d7ba-71b5-9cab-7c473cdcf54a
    statement: "`provenance` is `{ workspaceSchemaVersion, scope, resources,
      contexts, versions, adapters, gitCommit? }`: `scope` repeats the roots,
      `resources` lists every resource's identity and revision, `contexts` the
      resolved render contexts of included Evidence, and `versions` the
      producing tool versions, including `uiux`."
  - id: 01a115cd-d7f6-74a1-ba9f-c20a24a31ae5
    statement: Each `provenance.adapters` entry is `{ moduleSpecifier, adapterId,
      apiVersion, moduleIdentity, packageVersion?, contentDigest? }` with a
      `packageVersion` or a `contentDigest`, and `adapterId`s are unique.
  - id: 01a115cd-d832-7bfc-800d-c6fa8dd58dd2
    statement: "`readiness` is `{ implementationReady, coverage: { validation,
      evidence, review }, blockingDiagnostics }`, where `implementationReady` is
      a boolean that is never `true` while any diagnostic has `blocking: true`."
  - id: 01a115cd-d86c-72f0-a98c-fe8eb193d1b2
    statement: "Each `blockingDiagnostics` entry is `{ code, message, blocking,
      path? }`; advisory entries share the list with `blocking: false`."
  - id: 01a115cd-d8a7-7cd4-a54c-f557821dce80
    statement: "`coverage.validation` and `coverage.evidence` are each `{ complete
      }` with a boolean `complete`: `coverage.validation.complete` states that
      the closure is valid, and `coverage.evidence.complete` that every closure
      View has its required Evidence."
  - id: 01a115cd-d8e3-7976-ad6f-8f72af6a2d8a
    statement: "`coverage.review` is `{ complete, threads, workspaceThreads,
      resolved }`: `complete` is false while a closure thread is unresolved,
      `threads` counts closure threads, `workspaceThreads` the Workspace threads
      among them, and `resolved` maps each resolution kind to its count."
  - id: 01a115cd-d922-7728-a8f5-608889f8b510
    statement: An unresolved closure thread is the blocking diagnostic
      `handoff.unresolved_review_thread`, and a `wont-fix` thread the advisory
      `handoff.review_declined`.
constrains:
  - 01a111e4-0272-7c81-aa89-df553ee4de7c
