## Notes

- Import batch 7 created this Contract. Addresses are the paths and query keys the Workbench SPA reads; they are not HTTP API routes (owner ruling Q4: no HTTP Contract).
- Not normative: the area paths themselves (`/`, `/flows`, `/reviews`, `/members`, `/workspace/locales`, `/workspace/assets`) beyond those named here; the sign-in path `/login` belongs to the Access Contract's Feature.
- Part 11 (Discussion #122, R33) puts the selected version and comparison in the address (01a11a5e-1afd-79e8-bfe8-8c0eccfaa396); the owner rulings of 2026-10-09 (https://github.com/DevilTea/uiux/discussions/122#discussioncomment-18825439) name their query keys, recorded in 01a11e0d-d74b-701a-9a25-a149e400b7ec and 01a11e0d-d7f5-7ef8-ac22-e235d4a00a41. `compare=parent` selects the parent of 01a11e0d-d550-78e4-9787-f0023bbc1b93. Defaults for omitted `version`, `compare` and `canvas` are not ruled and left to implementation.
