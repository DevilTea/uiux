- Why a Contract: the command surface spans the CLI, network access and access Features, and users, scripts and CI depend on it independently of any one Feature.
- Output wording, the default port (3000, `PORT`) and the bind-host environment variables are implementation details at code@17d4165, not part of this Contract.
