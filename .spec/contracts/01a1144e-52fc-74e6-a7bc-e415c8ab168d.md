## Notes

- Why a Contract: the command surface spans the CLI, network access and access Features, and users, scripts and CI depend on it independently of any one Feature.
- Output wording, the default port (3000, `PORT`) and the bind-host environment variables are implementation details at code@17d4165, not part of this Contract.
- For `uiux init`, `--workspace <dir>` names the Workspace directory to create, so `<dir>` holds `workspace.json` directly. The refusal of 01a1144e-5649-7ba2-bb90-ad49658f0400 also covers a `.uiux/` in the home directory (Discussion #139 decision 2).
- `uiux access copy --from <old-dir>` keeps naming the old Workspace root, whose real path keyed the roster (01a11485-f874-73b4-8b0f-2295c21e9085); Discussion #139 decision 15 relies on it unchanged.
- 01a1144e-55be-785d-b494-7f7da834572a is listed among the CLI units that Discussion #139 amends but needs no change: it names no path, so "the manifest" means `workspace.json` in the selected Workspace directory (01a1144e-531c-7d71-9bc5-f62340aea55a), and the default directory and `--workspace` handling are owned by 01a1144e-55a3-74c4-8bf8-3205e968e275 and 01a1144e-5584-7101-98c0-dc3cbadbacdf.
