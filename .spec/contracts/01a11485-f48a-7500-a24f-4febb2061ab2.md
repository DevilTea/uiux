## Notes

- Why a Contract: MCP is the external agent interface; agents and their configurations depend on it independently of any one Feature.
- Owner ruling 2026-10-07 (checkpoint C): tool input and output field shapes are authoritative in code at 20c427c (`src/mcp/server.ts` zod schemas); the Clauses fix which tools and Resources exist and what they do. The Review-specific semantics of the Review tools belong to the Review Features (import batch 4); the Review discovery filters are 01a11544-6d38-7c63-958a-e0133b131fd3.
- The MCP transport is the SDK's stateless per-request HTTP handler; that choice is implementation detail.
