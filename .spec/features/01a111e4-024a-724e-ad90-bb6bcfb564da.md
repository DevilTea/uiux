id: 01a111e4-024a-724e-ad90-bb6bcfb564da
title: Click-to-comment targeting
summary: "Targeting interactions in the Preview: the Select and Comment modes,
  hit testing, hover candidates and commits, Escape, focus and teardown, pins in
  comment mode, and suppressing Widget Events while targeting."
rules:
  - id: 01a11658-2066-7f38-9f08-0f5f053b9762
    statement: The Select tool holds an inspection interaction, the Comment tool a
      comment-range interaction, and the Interact tool none.
  - id: 01a11658-20a8-72f2-afa2-263d19d8aba3
    statement: Without an active interaction the Preview reports no hover candidate
      or commit, so clicks under the Interact tool never cross the boundary.
  - id: 01a11658-20ee-7d89-a9b8-6da915e323b3
    statement: During targeting the Workbench never covers the Preview with a
      capture layer, forwards synthetic pointer events into it or infers the
      target from cached geometry.
  - id: 01a11658-2131-7302-8a66-1f550e3a5b10
    statement: A hover candidate is drawn as a transient, non-interactive outline
      from current stream geometry only, and becomes the structural selection
      only when committed.
  - id: 01a11658-217f-71e7-85ad-049ea3983cb1
    statement: Touch input has no hover candidate, and a tap commits the target.
  - id: 01a11658-21c1-7f67-8158-7516905a6a98
    statement: "Escape pressed inside the Preview during comment mode is only an
      intent: the Workbench performs the mode exit, clears its overlays and runs
      any queued navigation."
  - id: 01a11658-2203-7332-a5ee-1874535ce437
    statement: Moving focus from the Preview to Workbench UI clears the hover
      candidate but does not exit the targeting mode.
  - id: 01a11658-2245-7116-8f16-6c21910bae0d
    statement: A generation change during targeting discards that generation's
      uncommitted targeting state; the mode may stay, accepting input again only
      after the new generation completes its handshake.
  - id: 01a11658-2288-718c-a87e-20f6ded1b85c
    statement: While any targeting interaction is active, whatever its purpose, no
      Widget Event advances the Prototype player, and none from that time is
      replayed afterwards.
  - id: 01a11658-22cb-7e4c-9b88-0619588734fa
    statement: In comment mode, clicking a pin, pin cluster or edge indicator opens
      its thread instead of starting a new comment, while pointer input
      elsewhere still reaches the Preview.
  - id: 01a11658-230d-796c-9dbe-4dec53db9f47
    statement: Under the Select tool a click commits the Widget as the selection and
      still reaches the Widget's own handlers in the Preview.
