---
id: 01a111e4-013f-7b36-9e39-c57afb0bd320
title: View Variants
summary: "Named Variants of a View: sparse presets of initial Widget Runtime
  State, their name-based identity, how invalid Variants are kept and reported,
  and the read of a Widget's base-state value that the Inspector's Base cell
  shows beside a Variant's overrides."
rules:
  - id: 01a1144e-51e9-7e11-94c0-816baab9e0d6
    statement: "A named Variant is a sparse preset of initial Widget Runtime State:
      its `state` stores only the State members it overrides, and every Widget
      or member it omits keeps the IR and plugin defaults."
  - id: 01a1144e-51fc-713c-b456-2a65d0502678
    statement: "Rendering a View without a Variant uses its canonical base state:
      the IR plus plugin defaults, with no preset applied."
  - id: 01a1144e-520f-7456-9b7a-eb6b97fc0f75
    statement: Selecting, switching or capturing a Variant builds a fresh Runtime
      from the View IR with that Variant's overrides; it never inherits
      interaction state from an earlier Runtime.
  - id: 01a1144e-5222-78a3-853c-a6475ad0186b
    statement: "A Variant's name is its stable View-local identity: other resources
      reference a Variant by its View UUID plus Variant name, and there is no
      secondary Variant ID or registry."
  - id: 01a1144e-5236-769f-b516-222c05b2f48e
    statement: Renaming a Variant is an explicit identity change that requires
      updating the references to it.
  - id: 01a1144e-524c-7715-8fd8-d9ce46969cc6
    statement: An invalid Variant (an unknown Widget ID, an unknown or
      non-author-writable State member, or an invalid value) keeps its authored
      data for repair, and until it is valid it cannot be used, even partially,
      for render, capture or formal Review Evidence.
  - id: 01a1144e-5260-7290-897e-106a9c0dd914
    statement: UIUX reports all determinable diagnostics of an invalid Variant
      together, inline and in Checks.
  - id: 01a19a9d-9d1b-7db9-a535-96dedc258395
    statement: A Widget's base-state value is read from a separate Runtime built
      from the open View with no Variant and the render context's Locale,
      viewport and theme kept.
  - id: 01a19a9d-a01a-72bd-9ea0-cad4e90ae7fc
    statement: For each State member the open Variant overrides on the selected
      Widget, the Inspector's Base cell shows the base-state value, a pending
      state while its request is outstanding, or Unavailable when it cannot be
      read, never an authored default or a guess.
  - id: 01a19ab9-d787-7025-a293-7788659bb0b0
    statement: The base Runtime is never mounted, emits no Widget Event, produces no
      Checks entry or geometry, changes no live Runtime, Evidence or canonical
      resource, and is disposed after the read.
