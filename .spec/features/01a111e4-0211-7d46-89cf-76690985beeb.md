title: Formal UX Flow Evidence
summary: "Formal Evidence for a UX Flow: the replayable traversal trace and its
  captures, the Evidence-owned replay recipe and its immutability, and how
  Review and Handoff use Flow Evidence."
rules:
  - id: 01a11544-6628-73b9-b10a-9643d264bea1
    statement: Formal UX Flow Evidence is a deterministic, replayable trace with its
      required Playwright captures, recording the entry context and, per
      traversed step, its identity, View and Variant, triggering Widget Event,
      resulting step, validation result and Evidence references.
  - id: 01a11544-6655-7786-8185-f3e8c8d2c706
    statement: UIUX executes and verifies the playback with Playwright; a manual
      screenshot sequence or prose walkthrough is never formal Flow Evidence.
  - id: 01a11544-6681-7387-bdc3-9b825261f887
    statement: A trace identifies each transition by its source step, trigger and
      resulting step, never by a transition ID.
  - id: 01a11544-66ad-73e5-8fcd-9e24bfcb3313
    statement: The Playwright actions and assertions that drive a replay belong to
      the Evidence record, never to the Flow or to Adapter Event metadata.
  - id: 01a11544-66d9-7fcd-8400-93516ddf2857
    statement: A replay must show that its recorded actions produce the expected
      Widget Event and transition, so the Evidence proves the semantic
      transition rather than browser operations.
  - id: 01a11544-6707-70a7-b544-590b4f1e8a91
    statement: "A replay recipe is immutable with its Evidence: changing it creates
      new Evidence, and a copied earlier recipe is only an authoring starting
      point."
  - id: 01a11544-6734-7a24-a957-e23ddeb3e396
    statement: A Handoff manifest references Flow traces and captures as derived
      artifacts, while the canonical Flow is an authored Handoff resource.
  - id: 01a11544-6760-7ec2-8430-0f7cc5807259
    statement: A Review submission may name UX Flow as a change domain and reference
      specific Flows and their traces.

## Implementation gaps

- 01a11544-6628-73b9-b10a-9643d264bea1: Partly built as of 33bca1f: the trace records the render context, each entered step, its View and Variant, trigger, resulting step and capture, but its per-step validation result is always `true` (a recipe or Flow that does not validate is refused, not recorded) and the playback is not a browser traversal (see the next gap) ([code@33bca1f `src/application/services/flow-evidence.ts`](https://github.com/DevilTea/uiux/blob/33bca1f/src/application/services/flow-evidence.ts)); tracked in issue #88 (https://github.com/DevilTea/uiux/issues/88).
- 01a11544-6655-7786-8185-f3e8c8d2c706: Partly built as of 33bca1f: Playwright executes only the formal captures of the entered Views and Variants; the recipe's steps and triggers are evaluated by the server against the canonical Flow; tracked in issue #88 (https://github.com/DevilTea/uiux/issues/88).
- 01a11544-66d9-7fcd-8400-93516ddf2857: Partly built as of f56a91c: an `interaction_replay` record dispatches real browser actions in the Preview and asserts the Widget Event they cause (`src/application/services/interaction-replay.ts`, shared by every replay), but a `flow_trace` replay still does not: it evaluates each trigger against the canonical Flow, because a Flow trigger names a Widget Event (for example `press`) that has no defined browser action; tracked in issue #88 (https://github.com/DevilTea/uiux/issues/88).
- 01a11544-6734-7a24-a957-e23ddeb3e396: Not built as of 33bca1f: Handoff export references formal captures, not `flow_trace` records or the captures they reference; tracked in issue #88 (https://github.com/DevilTea/uiux/issues/88).
- 01a11544-6760-7ec2-8430-0f7cc5807259: Partly built as of 1e23d79: a submission's `evidenceRefs` accepts any Evidence kind, but `list_resources`, the Evidence list and the freshness judgement read `formal_capture` records only, so a `flow_trace` is neither listed nor judged fresh or stale for a Review submission (`src/application/services/formal-capture.ts`); tracked in issue #88 (https://github.com/DevilTea/uiux/issues/88).
