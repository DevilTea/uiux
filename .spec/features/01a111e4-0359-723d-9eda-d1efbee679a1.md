id: 01a111e4-0359-723d-9eda-d1efbee679a1
title: Workbench accessibility
summary: "Accessibility of the Workbench chrome: the conformance level in both
  themes, non-pointer paths for canvas actions, focus after canvas commits,
  target sizes and the minimum text size."
rules:
  - id: 01a1170f-c352-7e37-98e2-51b79ebb5776
    statement: A muted pin's accessible name includes its recorded render context,
      so its muted state never depends on color alone.
  - id: 01a116f0-941b-7d94-8a7c-7f83186e9b06
    statement: The Workbench chrome conforms to WCAG 2.2 level AA in both the light
      and the dark theme.
  - id: 01a116f0-9461-77fe-8ce2-ee89ba0d4ef0
    statement: Interactive chrome targets are at least 24 by 24 CSS pixels, and at
      least 44 by 44 on touch layouts.
  - id: 01a116f0-94a5-775a-aa3d-da41c3521555
    statement: Every canvas action has a path that needs no pointer.
  - id: 01a116f0-94ea-7b74-a773-12147804a393
    statement: A Widget can be chosen as a comment target from the Widget tree by
      keyboard, without pointing into the Preview.
  - id: 01a116f0-952d-7aa4-9a16-2648b1852daa
    statement: On touch, no action or information depends on hover.
  - id: 01a116f0-9573-7036-a9ca-76c6de6d829c
    statement: No chrome text is smaller than 12 CSS pixels, in either chrome language.
  - id: 01a116f0-95b9-7625-b40c-e51136aa45c5
    statement: After a click commits a Select or Comment target inside the Preview,
      keyboard focus returns to the canvas so Workbench shortcuts keep working.

## Notes

- WCAG 2.2 AA includes text and non-text contrast and visible focus that chrome never obscures (PRODUCT.md); the verified contrast table and focus colors are DESIGN.md visual specification (owner ruling Q7) and are not imported. Escape leaving targeting is owned by 01a11658-21c1-7f67-8158-7516905a6a98.
- Not verified by this import: overall WCAG conformance and the 44 px touch targets; the repository tests cover the contrast table, focus contrast and the 12 px floor (`tests/workbench-browser.test.ts`, `tests/workbench-theme-static.test.ts` at 673d086).
