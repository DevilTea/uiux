title: UX Flow graph
summary: A UX Flow is one canonical JSON resource of keyed steps, each targeting
  a View and an optional Variant, with nested outgoing transitions triggered by
  a Widget Event `{ widgetId, event }`; transitions have no UUID of their own,
  an ambiguous trigger is invalid, invalid references are preserved as
  diagnostics, and an optional opaque `scenarioRef` points to an external
  scenario.
