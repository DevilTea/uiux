summary: "The UX Flow graph: steps and their View and Variant targets,
  Widget-Event transitions and their identity, graph validity, invalid
  references, the external scenario reference, and the Workbench graph editor."
rules:
  - id: 01a11544-6147-70b2-969a-1d8b4997d581
    statement: "A UX Flow is a design and prototype specification, not a production
      router: UIUX generates no navigation code from it."
  - id: 01a11544-6172-7b9f-a8d6-3412aa2f04e7
    statement: "A step that names no Variant targets its View's canonical base
      state: the View IR and plugin defaults with no Variant preset applied."
  - id: 01a11544-619c-7fe1-a1b0-7e4695c28094
    statement: A transition is triggered by a semantic Widget Event occurrence,
      identified by its source Widget and declared Event name; Widget Methods
      and DOM events are never navigation triggers.
  - id: 01a11544-61c5-758e-90d6-5dc45e1cb55c
    statement: Transitions match only a Widget Event's identity, never its
      arguments, so branching needs distinct semantic Events.
  - id: 01a11544-61f0-76f1-a5a0-7bfa67408df9
    statement: Within one step a Widget Event trigger leads to at most one
      transition; a duplicate trigger is a validation error, never resolved by
      order or priority.
  - id: 01a11544-621a-79a1-b0fc-086c24c92488
    statement: "A transition has no identity of its own: its source step and trigger
      identify it, and the editor's edge keys are temporary."
  - id: 01a11544-6244-7a31-b37f-7f775a7d072a
    statement: Every step must be reachable from the entry step; an unreachable step
      is kept for repair but is a validation error that blocks complete
      execution and formal Evidence.
  - id: 01a11544-6270-76ac-939c-2816a124d094
    statement: Cycles and self-loops are valid, and a step without outgoing
      transitions is terminal without any flag.
  - id: 01a11544-629c-7dbf-8e41-36c8e37537b3
    statement: Invalid View, Variant and Widget references are preserved verbatim
      with structured diagnostics and never rebound by name, type, selector,
      position or similarity.
  - id: 01a11544-62c8-7d37-933b-b991fed72e30
    statement: A remaining invalid step or transition reference blocks complete
      execution, formal Flow Evidence and executable Handoff claims, while the
      Flow stays editable and its valid steps previewable.
  - id: 01a11544-62f1-7d7e-93a2-33691c947f24
    statement: Flow validation never checks a trigger's Event name against the
      Widget's declared Events, so an undeclared Event stays valid.
  - id: 01a11544-6324-7a4b-96e2-8428465588bb
    statement: UIUX never imports, mirrors, authors, synchronizes or validates the
      scenario a Flow's scenario reference points to, and failing to resolve it
      never changes the Flow.
  - id: 01a11544-6358-72ae-95ed-589ac1837f39
    statement: The Workbench edits a Flow in a node-and-edge graph editor backed
      directly by the one canonical Flow, with structured editing of the
      selected step or transition.
  - id: 01a11544-6386-77b6-aa9f-f767db5deb3c
    statement: When a trigger Widget's declared Events are known, the Flow editor
      offers them in a picker, and an existing undeclared Event stays selected
      and labelled, never cleared or rebound.
  - id: 01a11544-63b1-7363-9d65-cf94d90a091f
    statement: Agents can validate a Flow and play it back through MCP Tools,
      besides creating, reading, listing and updating it.
