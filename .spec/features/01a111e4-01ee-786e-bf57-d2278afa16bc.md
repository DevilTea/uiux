title: Comment pins
summary: "Comment pins on the Workbench canvas: the optional persisted pin hint
  and how it is set, moved, cleared and kept out of other records, where pins
  are drawn, and when they are hidden."
rules:
  - id: 01a11544-5b6b-7f09-9b0e-dd658d4e4684
    statement: "A thread's pin hint is display data only: anchor resolution,
      validity, comparison, filtering and re-anchoring never read it."
  - id: 01a11544-5b92-7a3f-9c75-bebbe43b76da
    statement: A pin hint is never validated against the View, the Widget's
      existence or size, a Variant or a render context.
  - id: 01a11544-5bb8-7cae-b9c1-10795b0620f7
    statement: Creating a thread may set its pin hint.
  - id: 01a115cd-2fde-72d5-a7ef-78e1333caf8a
    statement: A thread without a pin hint draws its pin at the default placement.
  - id: 01a11544-5bde-74a8-bb73-31a20bd17284
    statement: A re-anchor that supplies a pin hint sets the thread's hint to it.
  - id: 01a115cd-3037-759d-a728-e50a694cb577
    statement: A re-anchor that explicitly clears the pin hint leaves the thread
      without one.
  - id: 01a115cd-3065-7c3c-b557-ab2597608ffa
    statement: A re-anchor that neither supplies nor clears a pin hint clears it
      when the anchored Widget changes.
  - id: 01a115cd-3094-7aa5-9929-02cd217f7446
    statement: A re-anchor that neither supplies nor clears a pin hint keeps it when
      only the Variant scope changes.
  - id: 01a11544-5c04-7c32-8ca5-2ca0ad5fed11
    statement: Re-anchoring a thread to the Workspace always clears its pin hint.
  - id: 01a11544-5c2c-7a3b-ad39-f6c0839cf07e
    statement: Moving or clearing a thread's pin within its Widget is a separate
      action that never changes the anchor, records no actor and appends no
      history event.
  - id: 01a11544-5c53-7b73-b08f-1fe6c6880df7
    statement: The Workbench writes a moved pin once, when the drag ends, never
      streaming intermediate positions.
  - id: 01a11544-5c79-7c07-8b56-0eef56e0cec6
    statement: Pin hints never enter lifecycle or re-anchor history, submissions,
      Evidence records, formal captures or Decision provenance.
  - id: 01a11544-5ca0-7b99-9d32-43f3de4122be
    statement: Re-anchoring back to an earlier Widget never restores the hint the
      thread had there.
  - id: 01a11544-5cc6-7e81-9a4d-b7a0383fa7e9
    statement: A hinted pin is drawn at the hint's point within the anchored
      Widget's current rendered rectangle, so it follows the Widget when it
      resizes or reflows, in every viewport.
  - id: 01a11544-5cec-7711-8326-5e0fa5a89922
    statement: Pin hints are physical coordinates, so a pin keeps its side in a
      right-to-left Locale.
  - id: 01a11544-5d12-7146-9dc0-a05068a6ee77
    statement: A pin is hidden, never clamped or moved elsewhere, when its point is
      clipped or occluded, its Widget is not rendered, the geometry is stale,
      pending or unmeasurable, or the outer mapping is not affine.
  - id: 01a11544-5d39-733d-9581-eccc137f7263
    statement: A thread whose pin is hidden stays listed and navigable.
  - id: 01a11544-5d60-705e-b88a-d2e8743cba14
    statement: A thread with an invalid anchor draws no pin anywhere, and its hint
      stays inert until the same Widget resolves again.
  - id: 01a11544-5d87-7784-8b47-59de8187e492
    statement: Pins are drawn only for threads whose Variant scope is empty or
      includes the current Variant.
  - id: 01a11544-5dad-7d4c-b8e4-e1080c880bda
    statement: Workspace threads have no pin and never appear on a View's canvas or
      in its Comments list.
  - id: 01a11544-5dd6-78e1-a187-334dcd6d93f5
    statement: Dismissed threads never draw pins, even when the canvas shows
      resolved threads.
  - id: 01a11544-5e04-79f4-bc99-5b9b504ebad6
    statement: "A comment's click point is transient: it only positions the
      composer, and the server never receives it except as a derived pin hint."
