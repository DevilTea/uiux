title: Structured View Spec
summary: "The structured Spec each View carries beside its IR: explicit empty
  values, and how it references other Views and external material."
rules:
  - id: 01a1144e-5288-7d65-aba7-d47588111280
    statement: A View's Spec is a structured specification kept in the same View
      file as its IR and Variants but conceptually distinct from the executable
      IR; the Workspace persisted format Contract lists its fields.
  - id: 01a1144e-529b-741c-baf7-023bc5ca0aa8
    statement: Empty Spec content is stated explicitly, never by omitting a field;
      whether a Spec is complete is judged by Checks and Review policy, not by
      which fields are present.
  - id: 01a1144e-52ae-71d6-abe5-3adcc46854ad
    statement: A View reference records a design relationship to a View, optionally
      to one of its Variants; it never becomes a UX Flow edge or a runtime
      route.
  - id: 01a1144e-52c2-7628-83c0-1b50cef6cc15
    statement: "An external reference is identified by its URI alone: UIUX defines
      no provider-specific source or ID semantics, no other field of the
      reference is part of its identity, and its label is non-authoritative
      display text."
  - id: 01a1144e-52d5-795b-9881-4b214f87ffeb
    statement: UIUX does not fetch, mirror, synchronize or domain-validate the
      content behind an external reference, and an unreachable URI never
      rewrites the Spec.
