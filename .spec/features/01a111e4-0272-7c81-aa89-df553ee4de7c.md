title: Handoff export
summary: "Handoff export: roots and their dependency closure, bundle
  immutability, implementation-source references, Adapter and Locale content,
  and closure-scoped readiness including Review coverage."
rules:
  - id: 01a115cd-c77d-7ab3-9628-96ab2d85e233
    statement: Handoff generates no production code.
  - id: 01a115cd-c7b1-70f2-b02a-b69e556da439
    statement: Canonical resources enter a bundle verbatim in their own source
      formats, never converted into a second equivalent schema.
  - id: 01a115cd-c7e5-7273-9618-0f9c3c4f67db
    statement: An export starts from explicit typed roots, and a View's feature tag
      is never a root or an export boundary.
  - id: 01a115cd-c82f-7ce1-acd6-480f55774999
    statement: A bundle holds the deterministic transitive closure of its roots,
      including Flow target Views and Variants, bound Assets, applicable Locale
      files, Adapter and source provenance, and selected formal Evidence.
  - id: 01a115cd-c86c-7a84-964f-8a2b7bcd0a18
    statement: Whole-Workspace export is a convenience preset that roots every
      resource of the Workspace.
  - id: 01a115cd-c8a4-71c2-b066-65cb19c8cf14
    statement: An Asset or derived artifact that the closure does not reach never
      enters a bundle.
  - id: 01a115cd-c8db-7df8-87e8-8550c3800a59
    statement: An exported bundle is immutable, and exporting again creates a new
      bundle instead of changing an earlier one.
  - id: 01a115cd-c910-7e30-9b62-f210450ed108
    statement: Downstream implementers, human or Agent, consume a bundle read-only,
      starting from its root manifest and following its references.
  - id: 01a115cd-c945-7a9e-b108-f0391086ca42
    statement: A coherent bundle may be exported for a scope that is incomplete,
      invalid, under-evidenced or not fully reviewed.
  - id: 01a115cd-c97b-7691-9d72-87d4016889d3
    statement: Only a bundle whose closure passes the formal readiness gate claims
      implementation-ready; any other bundle is a diagnostic snapshot that
      implies no readiness.
  - id: 01a115cd-c9b0-7712-84fe-558740320b05
    statement: Problems outside a bundle's roots and their closure never affect its
      readiness.
  - id: 01a115cd-c9e5-78b1-9566-060014d24547
    statement: Any blocking problem or missing required Evidence inside the closure
      prevents the readiness claim.
  - id: 01a115cd-ca1a-75ec-b635-df569c795be8
    statement: Each View in the closure needs at least one fresh formal capture with
      complete coverage before the bundle can claim readiness.
  - id: 01a115cd-ca50-70b3-a65c-bd1c9f74aba4
    statement: Only fresh formal captures of closure Views enter a bundle as
      Evidence; stale captures are left out.
  - id: 01a115cd-ca85-71aa-9861-210acf22441d
    statement: Every Review thread anchored to a View in the closure is in the closure.
  - id: 01a115cd-cab9-78d1-a3eb-12185f6e701e
    statement: Every Workspace thread is in the closure of every export, so an
      unresolved one blocks readiness for every root.
  - id: 01a115cd-caee-7be7-913e-0312303148f8
    statement: A closure thread blocks the readiness claim only while it is open or
      ready for review; every resolution counts as closed.
  - id: 01a115cd-cb26-706a-916c-3df36b06c5e8
    statement: Only a verified resolution counts as an Evidence-checked change;
      every other resolution counts as closed without one.
  - id: 01a115cd-cb5e-760e-a74b-fedba2262f37
    statement: Each won't-fix thread in the closure adds a non-blocking advisory
      diagnostic naming the thread, which never changes readiness.
  - id: 01a115cd-cb95-74ac-8f1b-ac8adf567e59
    statement: For every Widget type the closure uses, a bundle makes the Widget
      plugin's semantic source and its renderer integration traceable, with the
      referenced Design System source where relevant.
  - id: 01a115cd-cbcc-7ae2-856e-b0fe1248c1ac
    statement: Adapter-provided mappings select the curated sources, and each
      materializable file is snapshotted by content identity with its original
      package or repository, revision and path.
  - id: 01a115cd-cc01-7365-b9ff-5535910173e9
    statement: A source that cannot or must not be embedded is marked
      provenance-only or unavailable, never silently dropped.
  - id: 01a11a5a-5845-7fc4-99b8-b0fe62039460
    statement: A used Widget type without an Adapter source mapping is traced to its
      Adapter's entry module as both its semantic and its renderer source, and
      its references record that fallback.
  - id: 01a11a5a-58c6-70bd-9a05-54e533e57c53
    statement: A mapped source the Adapter marks not to embed, or gives only as a
      URL, is provenance-only.
  - id: 01a11add-f389-70cc-8449-6ae596044963
    statement: A mapped source file that is missing or unreadable is unavailable.
  - id: 01a11a5a-594b-74b6-92af-dce82ecfeaef
    statement: A provenance-only or unavailable Adapter-mapped source never blocks
      the readiness claim.
  - id: 01a115cd-cc36-7160-a2b6-baadcf98e40b
    statement: A bundle records every active Adapter, in Adapter-list order, with
      its authored selection and resolved provenance.
  - id: 01a115cd-cc70-751d-aac2-3306e6db4c24
    statement: A local Adapter without a reliable package version is identified by
      the content digest that the Handoff bundle Contract defines.
  - id: 01a115cd-cca5-77d1-b2d4-f5ce09f41b2b
    statement: Adapter provenance is an export-time snapshot and never rewrites the
      Workspace's Adapter configuration.
  - id: 01a115cd-ccda-7175-8ab7-2820b370e2a7
    statement: A bundle keeps each View's authored translation bindings together
      with the parameter-name bindings, or their provenance, needed to
      understand them.
  - id: 01a115cd-cd10-7938-af6f-9d466bb0c5e1
    statement: UIUX plumbing for Adapters and translation, such as mapped Property
      names, translation results and live warnings, is never a production-data
      contract of a bundle.
  - id: 01a115cd-cd45-710c-a951-1b4fef78597d
    statement: Handoff provenance never enters the canonical schemas of the
      resources it describes.
  - id: 01a11bb1-bd7c-7117-8c54-ceb9881db19c
    statement: A bundle includes a snapshot of the Product Kit file, so implementers
      get its style entries and theme attributes.
  - id: 01a11bb1-bde1-7146-abc4-31a3e7f4e371
    statement: The implementation reference of a used Widget type that the component
      table maps names its registry component, with each file materialized by
      content identity, or its external export.
