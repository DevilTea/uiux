id: 01a111e4-0184-794a-8ede-f7f856ffbe4c
title: Render context
summary: "Render contexts: Workspace-owned viewport and theme registries,
  Adapter theme validation, and live context switching in Preview."
rules:
  - id: 01a115cd-c27d-78ba-b95d-bf1aa50adec7
    statement: A theme that the active Adapters do not support is reported as a
      render-context diagnostic and never replaced by another theme.
  - id: 01a11a5a-5464-7797-82d3-f8ece37457e5
    statement: UIUX evaluates each active Adapter's theme support on the server,
      once per Adapter resolution, for every theme in the Workspace registry.
  - id: 01a11add-f46d-7e92-8f5a-9d10dba6473d
    statement: Settings, live Preview and formal capture all use the theme-support
      result of the current Adapter resolution.
  - id: 01a11a5a-54e2-7216-a5a1-0de226971850
    statement: An Adapter that declares no theme support supports every theme.
  - id: 01a11a5a-555f-7b4c-8fcc-311c31a99b7a
    statement: A theme-support predicate that throws or returns a non-boolean is an
      Adapter diagnostic, and the theme it was asked about counts as
      unsupported.
  - id: 01a11a5a-55ee-737a-9970-cb9228a2de30
    statement: A theme is unsupported as soon as any active Adapter rejects it,
      whether or not a View uses that Adapter.
  - id: 01a11a5a-566b-70b1-b000-2918519c0d19
    statement: Live Preview shows the render-context diagnostic instead of rendering
      a context whose theme is unsupported, and formal capture refuses that
      context.
  - id: 01a11a5a-56e8-71c8-905a-62ed0476fd8f
    statement: An unsupported theme leaves the Adapter set valid, and contexts with
      supported themes keep rendering.
  - id: 01a11a5a-5769-721b-ad33-d068c7edeb41
    statement: The Product Kit page lists, for each Adapter, the Workspace themes it
      does not support.
  - id: 01a115cd-c2c0-7ec4-9fc8-a491f73f798a
    statement: Execution uses only theme and viewport IDs that exist in the
      Workspace registries.
  - id: 01a115cd-c2f7-7246-9446-e2325b631b5b
    statement: The Workbench may offer convenience viewport presets when one is
      created, but only presets saved in the Workspace are canonical.
  - id: 01a115cd-c32d-7594-8277-c17646f9a500
    statement: In live Preview, changing the Locale, viewport or theme keeps
      unrelated interaction state, such as entered values or expanded controls,
      while the Runtime stays valid.
