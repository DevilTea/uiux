id: 01a111e4-016a-764a-8947-93dbdd331904
title: Checks
summary: "The Workspace Checks surface: which findings it gathers, how it
  reports their origin and check state, how it groups, orders and navigates
  them, and what it leaves out."
rules:
  - id: 01a115cd-bb01-7830-abdc-43cf81dc0897
    statement: Checks lists diagnostic findings only, never Review status, approval
      queues or tasks.
  - id: 01a115cd-bb33-70a8-a09f-999e06ce38ed
    statement: Checks gathers translation reminders, current Preview translation
      warnings, structural and schema validation findings, current Runtime
      errors and Catalog problems of used entries.
  - id: 01a115cd-bb64-75c2-a7df-2c8dd338453d
    statement: Each finding keeps its origin, scope, check state and original
      severity or blocking meaning; Checks never merges sources into one warning
      type.
  - id: 01a115cd-bb96-7131-99d9-a3882829590c
    statement: Checks tells apart not yet checked, checking, completed with or
      without findings, and failed or incomplete, and never shows an unrun check
      as zero findings.
  - id: 01a115cd-bbc7-7f77-bc7c-c88a97367b0e
    statement: Opening Checks never runs validation, forces hidden Properties to
      evaluate or invokes `t`.
  - id: 01a115cd-bbfa-7022-b8f1-ef8734cbe45e
    statement: Run Checks explicitly produces or refreshes a complete check result,
      and live background warnings are never presented as a complete run.
  - id: 01a115cd-bc2c-795f-babe-0d19eb80de96
    statement: Each Run Checks produces a new immutable Evidence record of its
      result instead of overwriting an earlier one.
  - id: 01a115cd-bc5e-710e-bbe2-a3d5f51469fb
    statement: Checks never shows a Runtime error or translation warning from an
      earlier Preview, Variant or Locale as a current finding.
  - id: 01a115cd-bca6-7c80-b393-5b9260c2ce18
    statement: Listing a blocking structural or executable problem in Checks never
      weakens its Preview, capture or Review gating.
  - id: 01a115cd-bcde-797b-b9f4-dc60d7d853bd
    statement: Historical Review and capture Evidence never merges into the live
      Checks list.
  - id: 01a115cd-bd13-778b-8a0a-b4d43cd98aa7
    statement: Checks groups and filters findings by source, category, severity,
      View and Variant.
  - id: 01a115cd-bd48-7c10-82fc-827d5e8e5ba8
    statement: By default Checks orders findings by severity, then code or category,
      then stable View and Widget location.
  - id: 01a115cd-bd7d-705f-be59-b24cc4bd389e
    statement: "Selecting a finding opens its exact authoring context: the View,
      Variant, Widget, file or editor it concerns."
  - id: 01a115cd-bdb2-7de2-abb9-54f592539471
    statement: Translation reminders appear in Checks by Locale, key and reminder
      type and open the matching translation-table cell.
  - id: 01a115cd-bde8-736b-9153-7baaedf24f98
    statement: Checks groups translation warnings by key, warning code and missing
      parameter, each group counting and listing its affected Widget and
      Property occurrences.
  - id: 01a115cd-be1d-74aa-8639-23f43671e86d
    statement: Within a translation-warning group, occurrences are ordered by View,
      Variant, Widget, and Property or Catalog field.
  - id: 01a115cd-be51-740b-8472-c08dc7138e3e
    statement: Checks reports Catalog problems only for entries that at least one
      View uses; problems of unused entries appear only in Catalog management.
  - id: 01a115cd-be84-755b-b9fb-62f519cf989c
    statement: One Catalog problem shows once, expanding to each distinct affected
      View and then each distinct affected Widget, with separate counts at each
      level.
  - id: 01a115cd-beb7-7024-9e44-0b5fe9ecf9af
    statement: The affected Views and Widgets of a Catalog problem follow current
      Workspace usage without revalidating the Catalog.
---
