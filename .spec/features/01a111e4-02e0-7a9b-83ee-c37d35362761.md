summary: UIUX ships as the single public npm package `@deviltea/uiux` whose
  `uiux` binary initializes, serves, migrates and publishes one explicitly
  selected Workspace and manages that Workspace's access roster; its help and
  version output stay honest about what is shipped. `uiux publish` takes
  `--workspace <dir>` and `--out <dir>`, plus optional `--base <path>` and
  `--source-revision <rev>`.
