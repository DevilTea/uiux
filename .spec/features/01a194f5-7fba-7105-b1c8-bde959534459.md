  - id: 01a194f5-81a5-7b74-96b5-c4c018bae06c
    statement: An empty Workspace's Overview shows ordered first-run steps for
      getting a first View, in place of an empty list.
  - id: 01a194f5-838a-78ee-aa17-1c6a887d5669
    statement: For an unknown route the error page names the requested path and the
      status 404; for any other error it shows a generic message; both link back
      to Overview.
  - id: 01a194f5-8573-7218-82ec-7f7286186693
    statement: While the server is unreachable the Workbench shows a banner with a
      Retry action and removes it once the server answers.
  - id: 01a194f5-878c-78d4-8ffe-442c854539ee
    statement: The Preview host shows a distinct state for loading, no View, a load
      error and an unavailable Adapter, never a blank frame.
  - id: 01a194f5-896b-7547-8440-e59efa183082
    statement: Overview's Views tab filters Views by feature and by readiness, and
      shows Checking, Couldn't check and Can't check as states apart from ready
      and blocked.
