title: Translation runtime
summary: "Translating authored copy at run time: `$i18n` bindings and their
  lowering, the RootShell `t` Method with its fallback, markers, placeholder
  grammar and warnings, the reactive dependency boundary, and how live and
  formal evaluation collect translation warnings."
rules:
  - id: 01a115cd-b4be-791b-916e-8c2dade9a441
    statement: An ordinary string in a View's Config is literal copy, never a
      translation reference.
  - id: 01a115cd-b4f1-7348-b3d6-f0d834c73e34
    statement: Switching the Preview Locale never replaces or erases a View's
      authored translation binding.
  - id: 01a115cd-b523-7a29-81d4-5a60f9ee4176
    statement: Before Widget Core runs, UIUX lowers each translation binding to its
      literal key in the Catalog-mapped Config field, never to translated text.
  - id: 01a115cd-b552-70b9-add5-ab294b9214af
    statement: Widget Core and Vue renderers acquire no translation semantics.
  - id: 01a115cd-b581-7d3d-88eb-d1ca8fcfcdd8
    statement: A child Widget translates by calling the RootShell `t` Method from
      its own computed Property.
  - id: 01a115cd-b5b0-75e5-9c19-0682ad1736b9
    statement: A Vue renderer never receives `t` and reads localized text only from
      its Widget's Properties.
  - id: 01a115cd-b5e0-727a-9654-02f50d9d26c9
    statement: A localized Widget exposes a structured translation-result Property
      that calls `t` once and a plain-text Property that projects its text.
  - id: 01a115cd-b610-78ca-8e24-8448d3a350ac
    statement: The RootShell `t` Method is read-only and writes no State.
  - id: 01a115cd-b641-7cd6-a17b-9818509a1a73
    statement: The RootShell `t` Method depends only on the effective Locale, never
      on the sources of interpolation arguments.
  - id: 01a115cd-b670-7f67-86ae-541d41cc5a47
    statement: Each child Property declares and tracks the dependencies of its own
      interpolation arguments.
  - id: 01a115cd-b6a0-7058-81d5-c2f96d304801
    statement: Changing an interpolation argument recomputes only the affected
      Properties, without tearing down the Runtime or resetting other Widgets'
      state.
  - id: 01a115cd-b6cf-7994-a12e-93eb11beac6e
    statement: Mandatory Adapter Runtime conformance tests verify the dependency
      boundary between `t`, translation-result Properties and their parameter
      Properties.
  - id: 01a115cd-b6ff-79de-8d98-dcbd0c07c504
    statement: The `t` Method always returns renderable text with its warnings as a
      successful result; a recoverable translation problem never fails the
      Method.
  - id: 01a115cd-b732-79db-b872-ac27713f15f8
    statement: When the requested Locale lacks a key, `t` uses the default Locale's
      text and warns that it fell back.
  - id: 01a115cd-b763-7fd6-b1df-0b7b568c1879
    statement: When neither the requested nor the default Locale has the key, `t`
      returns the unresolved-key marker with a warning, never an empty string or
      the raw key.
  - id: 01a115cd-b794-78be-bec6-f0c9a8f9ac68
    statement: "A present Locale value that is empty or only whitespace is available
      copy: `t` returns it unchanged, without fallback, marker or warning."
  - id: 01a115cd-b7c5-7559-aac7-dbf746a828a0
    statement: A placeholder whose argument is absent renders the missing-parameter
      marker in its place and adds a warning.
  - id: 01a115cd-b7f7-752f-b3ca-4b9a1fb6277f
    statement: An argument supplied as an empty string is present, so it is
      substituted and never treated as missing.
  - id: 01a115cd-b826-71ab-afc0-4fa6a8f9e4b0
    statement: The `t` Method parses a message once, left to right, and never
      re-parses escaped text or interpolated values.
  - id: 01a115cd-b85c-7fcd-9b44-2633c0472e96
    statement: A malformed placeholder fragment renders literally, without argument
      lookup, warning or Method failure, and leaves valid placeholders elsewhere
      in the message intact.
  - id: 01a115cd-b88b-7cfe-84ad-cc9d081a6c9e
    statement: The unresolved-key and missing-parameter markers are design-time
      diagnostics and never count as valid production copy.
  - id: 01a115cd-b8bb-7b07-95b5-4eb10ab44857
    statement: Preview and the Workbench render `t` text, markers included, verbatim
      and derive diagnostics only from the structured warnings, keeping no
      second placeholder state.
  - id: 01a115cd-b8ec-7bd3-a601-8e3daee94957
    statement: Warnings from `t` describe only the translation problem; `t` never
      receives or reports the View, Variant, Widget or Property.
  - id: 01a115cd-b91d-7230-9041-b56ff70b814b
    statement: The Workbench attributes each warning to its View, Variant, Widget,
      result Property and Catalog field through the Catalog mapping and
      read-only Widget inspection.
  - id: 01a115cd-b94f-7a87-830c-2060f2e63a2e
    statement: Ordinary Preview reports warnings only for translation Properties the
      Runtime actually evaluated and never forces hidden or offscreen Widgets to
      evaluate.
  - id: 01a115cd-b983-7fc3-88fb-57247dd8082a
    statement: A translation Property that was never evaluated is unverified, and
      one whose evaluation failed or is missing is incomplete.
  - id: 01a115cd-b9be-7018-9247-003f129366f9
    statement: A translation Property's live warnings are those of its latest
      completed result, so each recomputation replaces them.
  - id: 01a115cd-b9fc-71d9-8bf9-91d65acd1096
    statement: Changing the Locale, Variant or Runtime clears the live warnings of
      the previous context.
  - id: 01a115cd-ba33-7f4f-afd5-a421c890bfee
    statement: Within one evaluation context a warning is identified by its Widget,
      result Property, key, warning code and missing parameter, so the same
      problem in different Widgets or Properties stays separate.
  - id: 01a115cd-ba68-7c73-a157-08ef34be1e54
    statement: Formal Review validation and capture evaluate every Catalog-declared
      translation-result Property of the target View and Variant, including
      hidden or not-yet-rendered Widgets.
  - id: 01a115cd-ba9b-70ba-a6ff-cf4649236a2c
    statement: A formal evaluation that cannot evaluate a declared Property records
      incomplete coverage with the missing occurrences and never claims a
      complete pass.
  - id: 01a115cd-bace-7333-a98f-5a760cd57f45
    statement: Formal translation Evidence never parses, duplicates or normalizes
      markers into a separate record.
