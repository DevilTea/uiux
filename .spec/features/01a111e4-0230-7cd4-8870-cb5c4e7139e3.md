id: 01a111e4-0230-7cd4-8870-cb5c4e7139e3
title: Preview session and runtime lifecycle
summary: "The Preview session and runtime generation lifecycle: session and
  generation identity and history, reload, restart and reconnect boundaries, and
  automatic and explicit recovery of a failed generation."
rules:
  - id: 01a1161c-3adb-7d40-a7bb-ea2765d81425
    statement: A Preview session spans iframe reloads, runtime restarts, transport
      reconnects, View and Variant navigation and generation changes; only a new
      Preview instance starts a new session.
  - id: 01a1161c-3b15-7913-acfb-136f0bd365b6
    statement: The Workbench never activates a Preview session whose ID matches one
      retired earlier in the same Workbench process; it discards that ID and
      generates another before the session begins.
  - id: 01a1161c-3b51-7ebd-bff2-987863a7c1cb
    statement: After a full Workbench restart, an open Workbench page starts a new
      Preview session, with a fresh generation and newly acquired geometry,
      before any geometry traffic resumes.
  - id: 01a1161c-3b93-74e5-993b-421a783a256d
    statement: A runtime generation that becomes protocol-invalid ends only that
      generation, never the enclosing Preview session.
  - id: 01a1161c-3bd4-7a91-b50e-d01a857521e5
    statement: After a generation becomes protocol-invalid, the runtime may start
      one fresh generation automatically in the same Preview session, with its
      own declaration and acknowledgement.
  - id: 01a1161c-3c0e-7274-8112-db507455e0f4
    statement: If the automatic recovery generation also becomes protocol-invalid
      during its handshake, no further generation starts until the Workbench
      authorizes an explicit retry.
  - id: 01a11a59-eecb-7aff-983b-972148c714e1
    statement: A generation that ends with a runtime-reported failure of the
      `runtime` category starts no automatic recovery generation; the next
      generation starts only from an explicit retry.
  - id: 01a1161c-3c49-71e4-b9d6-bbab46e97840
    statement: The automatic recovery allowance renews only when a fresh generation
      completes its handshake; creating a generation, declaring capabilities,
      reconnecting or waiting never renews it.
  - id: 01a1161c-3c83-7956-a6ad-43ecc1b21b83
    statement: While recovery is exhausted and no retry is authorized, the Workbench
      never acknowledges a new generation or accepts its traffic.
  - id: 01a11658-179e-7c94-b1cc-8e5c59ecc6ca
    statement: The Workbench retires the ID of a generation it refused while
      recovery was exhausted, without ending the Preview session.
  - id: 01a1161c-3cbe-7bdc-ba70-7d2bcc8d2591
    statement: While Preview capability is unavailable, the Workbench sends and
      accepts no geometry traffic.
  - id: 01a11658-1854-7e13-9089-a3fe4c53a33d
    statement: While Preview capability is unavailable, the Workbench keeps the
      structural Widget selection.
  - id: 01a11658-18a0-7b94-8411-17b46d344429
    statement: While Preview capability is unavailable, the Workbench shows the
      Widget highlight as unavailable.
  - id: 01a1161c-3cf8-7859-9de8-2b99d22ce8aa
    statement: One explicit retry authorizes exactly one fresh-generation attempt.
  - id: 01a11658-1929-763d-a634-7a2f6bf4711f
    statement: When the generation an explicit retry started fails, Preview returns
      to capability-unavailable.
  - id: 01a11658-196e-73c2-bf9e-078a9ea604f9
    statement: When the generation an explicit retry started fails, the automatic
      recovery allowance stays spent.
  - id: 01a1161c-3d31-7a69-9d64-cad14a8071bb
    statement: A retry authorization is spent when its fresh generation enters
      bootstrap, whatever the outcome of that generation's handshake.
  - id: 01a1161c-3d6d-77b3-81b2-aa3b017b3771
    statement: A pending retry authorization lasts until it is spent, revoked or its
      Preview session ends; nothing else, not even elapsed time, expires it.
  - id: 01a1161c-3dad-7ac1-b49b-a77fcb1e33f2
    statement: A retry trigger while an authorization is pending joins that
      authorization, so retry attempts never accumulate.
  - id: 01a1161c-3dec-7e23-b80a-a56f2620fdb5
    statement: The Workbench may revoke a pending retry authorization until its
      generation enters bootstrap.
  - id: 01a11658-1a35-7cfe-ba73-398878c589f9
    statement: Revoking a retry authorization and admitting its generation are
      serialized, and whichever commits first wins.
  - id: 01a1161c-3e28-7dcf-a06e-a2c12c83919c
    statement: A retry trigger while an authorized generation is still in its
      handshake creates no authorization and never replaces or cancels that
      generation.
  - id: 01a1161c-3e63-74d6-a883-ddf6492e83e5
    statement: Iframe reloads, runtime restarts, reconnects and View or Variant
      navigation never clear exhausted recovery or authorize a new generation.
  - id: 01a1161c-3e9d-7da7-b7d7-18caf1d8cf43
    statement: A new Preview session starts with an unspent automatic recovery
      allowance, no unavailable state and no retry authorization.
  - id: 01a1161c-3ed7-74ba-b9ee-19b88d6160e3
    statement: After a generation change the Workbench hides every highlight of the
      old generation and draws it again only from a complete geometry set
      acquired under the new generation, never showing old contours meanwhile.
