---
id: 01a111e4-0123-7ff7-a650-fd8c690e21d5
title: Workspace schema versioning
summary: How the single supported Workspace schema version is recognized, and
  how a Workspace at any other version is refused.
rules:
  - id: 01a1144e-4fe2-7bbe-82f2-e846e43def27
    statement: A Workspace whose `schemaVersion` is not the current one, older or
      newer, is `unsupported` and is reported with one clear schema diagnostic.
  - id: 01a1144e-4fcf-7b8a-8978-73b1a0cc31f4
    statement: While a Workspace is `unsupported`, every mutation, formal capture,
      Handoff readiness assessment and Handoff export is refused with the schema
      diagnostic that the Workspace persisted format Contract assigns.
  - id: 01a1144e-5079-7c4e-99a4-912094aba0d4
    statement: "UIUX has no Workspace migration: a release that raises the current
      `schemaVersion` ships no conversion, and no command, Tool or route
      upgrades a Workspace."
---
