---
id: 01a111e4-0123-7ff7-a650-fd8c690e21d5
title: Workspace schema versioning and migration
summary: How the single Workspace schema version is recognized, how a Workspace
  at an older or unsupported version is treated, and the explicit, CLI-only
  migration that upgrades it.
rules:
  - id: 01a1144e-4fba-7152-8239-5c348a832b10
    statement: A Workspace at a recognized older `schemaVersion` can be opened,
      inspected and explained, but UIUX never mutates or upgrades it implicitly.
  - id: 01a1144e-4fe2-7bbe-82f2-e846e43def27
    statement: A Workspace whose `schemaVersion` is unknown or newer than this UIUX
      supports is `unsupported` and is reported with one clear schema
      diagnostic.
  - id: 01a1144e-4fcf-7b8a-8978-73b1a0cc31f4
    statement: Until an older Workspace is migrated, and while a Workspace is
      `unsupported`, every mutation, formal capture, Handoff readiness
      assessment and Handoff export is refused with the schema diagnostic that
      the Workspace persisted format Contract assigns.
  - id: 01a1144e-4ff6-74c4-90c4-fd91439b1cb5
    statement: Migration runs only when an operator invokes `uiux migrate`; there is
      no MCP Tool and no HTTP route for it.
  - id: 01a114ec-86a4-7476-84d5-aa46f098bb18
    statement: While migration is required, the Workbench shows a read-only banner
      that names the `uiux migrate` command.
  - id: 01a1144e-5009-7818-abb5-1b26337671ee
    statement: Migration upgrades the Workspace's canonical files in place,
      deterministically and atomically, to the current `schemaVersion`; a
      failure leaves them unchanged, never partially migrated.
  - id: 01a1144e-501c-746b-9f23-4cd321628f7c
    statement: One run chains every migration step from the Workspace's version to
      the current one, in version order; the Workspace persisted format Contract
      names the steps.
  - id: 01a114ec-86ec-7127-a10d-710a04672586
    statement: Before anything is written, each step re-validates every Review file
      that was valid under its source version against its target version.
  - id: 01a1144e-502f-7a30-bf11-69d72ea164db
    statement: 'The step from version 1 to 2 sets `schemaVersion` to 2 and adds
      `resolution: "verified"` to every Review lifecycle event that entered
      `resolved` without a resolution.'
  - id: 01a1144e-5042-77ea-9146-808f5b46b8ef
    statement: The step from version 2 to 3 changes only the manifest
      `schemaVersion`, from 2 to 3.
  - id: 01a1144e-5054-7fc1-9c23-49ae8c9886c1
    statement: A dry run, `uiux migrate --dry-run`, plans the migration in memory
      and writes nothing.
  - id: 01a1144e-5067-7a2e-bd8d-e33a667033c2
    statement: A real migration refuses while a `uiux dev` server is serving the
      Workspace; a dry run still runs then and notes the serving server.
  - id: 01a1144e-5079-7c4e-99a4-912094aba0d4
    statement: A release that raises the current `schemaVersion` ships the matching
      migration step, its validators and the `uiux migrate` entrypoint together,
      so no released version decodes a new schema without handling it.
  - id: 01a11485-bb6d-7579-a7c4-592945041d6f
    statement: The step from version 1 to 2 synthesizes no Review pin display hints.
---
