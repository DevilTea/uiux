---
id: 01a111e4-0123-7ff7-a650-fd8c690e21d5
title: Workspace schema versioning and migration
summary: "The manifest records one Workspace `schemaVersion` (current: 3). An
  older recognized Workspace opens read-only until it is upgraded explicitly,
  atomically and deterministically through the CLI-only `uiux migrate` (with a
  writing-nothing `--dry-run`, refused while a `uiux dev` server holds the
  Workspace); there is no HTTP or MCP migration entrypoint. Until then,
  mutations, formal capture, Handoff readiness assessment and Handoff export
  refuse with `workspace.migration_required` (over HTTP, capture, assessment and
  export answer 422); a Workspace whose `schemaVersion` is unknown or newer than
  this UIUX supports is `unsupported`, and the same operations refuse with
  `workspace.schema_unsupported`."
rules:
  - id: 01a1144e-4fba-7152-8239-5c348a832b10
    statement: "A Workspace at a recognized older `schemaVersion` can be opened,
      inspected and explained, but UIUX never mutates or upgrades it implicitly:
      until it is migrated, every mutation is refused with
      `workspace.migration_required`."
  - id: 01a1144e-4fcf-7b8a-8978-73b1a0cc31f4
    statement: On such a Workspace, formal capture, Handoff readiness assessment and
      Handoff export are refused with `workspace.migration_required` too; over
      HTTP each answers 422.
  - id: 01a1144e-4fe2-7bbe-82f2-e846e43def27
    statement: "A Workspace whose `schemaVersion` is unknown or newer than this UIUX
      supports is `unsupported`: it is reported with one clear schema
      diagnostic, `workspace.schema_unsupported`, and mutations, formal capture
      and Handoff assessment and export are refused."
  - id: 01a1144e-4ff6-74c4-90c4-fd91439b1cb5
    statement: Migration runs only when an operator invokes `uiux migrate
      --workspace <dir>`. There is no MCP tool and no HTTP route for it, and
      while migration is required the Workbench shows a read-only banner that
      names that command.
  - id: 01a1144e-5009-7818-abb5-1b26337671ee
    statement: Migration upgrades the Workspace in place, deterministically and
      atomically, to the current `schemaVersion`; a failure leaves the Workspace
      unchanged, never partially migrated.
  - id: 01a1144e-501c-746b-9f23-4cd321628f7c
    statement: One run chains every step from the Workspace's version to the current
      one (`uiux.v1-to-v2`, then `uiux.v2-to-v3`), and before anything is
      written each step re-validates every Review file that was valid under its
      source version against its target version.
  - id: 01a1144e-502f-7a30-bf11-69d72ea164db
    statement: 'Step `uiux.v1-to-v2` sets `schemaVersion` to 2 and adds `resolution:
      "verified"` to every Review lifecycle event that entered `resolved`
      without a resolution; it synthesizes no pin display hints.'
  - id: 01a1144e-5042-77ea-9146-808f5b46b8ef
    statement: Step `uiux.v2-to-v3` changes only the manifest `schemaVersion`, from
      2 to 3.
  - id: 01a1144e-5054-7fc1-9c23-49ae8c9886c1
    statement: "`uiux migrate --dry-run` plans the migration in memory and reports
      the steps and the changed files without writing anything."
  - id: 01a1144e-5067-7a2e-bd8d-e33a667033c2
    statement: A real migration refuses while a `uiux dev` server is serving the
      Workspace; a dry run still runs then and notes the serving server.
  - id: 01a1144e-5079-7c4e-99a4-912094aba0d4
    statement: A release that raises the current `schemaVersion` ships the matching
      migration step, its validators and the `uiux migrate` entrypoint together,
      so no released version decodes a new schema without handling it.
---
