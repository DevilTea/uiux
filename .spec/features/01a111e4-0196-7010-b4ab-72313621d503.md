title: Formal Evidence capture
summary: "Formal Evidence capture: its engine and shared service, the explicit
  render contexts it runs, Runtime isolation per context, what a capture
  records, interaction-replay records, and how an Evidence error differs from
  findings inside Evidence."
rules:
  - id: 01a115cd-c361-7ac6-94c0-cdfbb82f4728
    statement: Formal capture runs Playwright with Chromium on the server.
  - id: 01a115cd-c395-72b0-be67-4a77c4d2ade4
    statement: HTTP, MCP, the CLI and the Workbench capture through one shared
      server capture service, and the Workbench never rasterizes the DOM itself.
  - id: 01a115cd-c3c9-76fd-8ccd-4a8664e52e7d
    statement: Formal capture runs an explicit list of resolved render contexts and
      never expands Variants, Locales, viewports or themes into an implicit
      Cartesian product.
  - id: 01a115cd-c3fd-7e82-aa05-737aac6c4354
    statement: Convenience selections, such as all current Variants or Locales,
      resolve into the explicit context list before capture runs.
  - id: 01a115cd-c431-7f76-bf29-a296b3e90407
    statement: A capture context without a Variant also starts from a fresh
      deterministic Runtime and never inherits state from an earlier capture
      context.
  - id: 01a115cd-c467-790e-8a3a-41b4d2cf1dd7
    statement: Formal capture renders the clean Preview Host, never Workbench Review
      chrome such as pins, highlights or overlays.
  - id: 01a115cd-c49d-7c39-87ed-7098ed135e5f
    statement: Each capture records the resolved context it actually executed, so a
      later registry change never alters what existing Evidence says it
      captured.
  - id: 01a115cd-c4d1-7c77-ab64-7b59f70ebc6c
    statement: Only a corrupt, schema-invalid or unverifiable Evidence record is an
      Evidence error; warnings inside a valid record are data.
  - id: 01a115cd-c507-738d-abd7-7a4194761319
    statement: Replaying interaction Evidence records pass or fail for each
      assertion together with the captures it requires.
