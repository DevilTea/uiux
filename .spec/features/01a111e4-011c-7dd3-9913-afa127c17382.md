---
id: 01a111e4-011c-7dd3-9913-afa127c17382
title: Workspace layout and identity
summary: "The Workspace as a self-contained, file-native directory selected
  explicitly by the CLI: where it may live, what it works without, how canonical
  resources are split into separately persisted units, and how each resource is
  identified."
rules:
  - id: 01a1144e-4ef7-742f-9673-7ffa087f74d2
    statement: A Workspace is the directory that a CLI command selects explicitly
      (see the Command-line interface Contract), and UIUX owns a fixed internal
      layout beneath that root.
  - id: 01a1144e-4f18-7346-90bc-18fad711e63c
    statement: A Workspace works without a production source tree, Git or network access.
  - id: 01a114ec-8552-787b-ba42-ea15526a51d6
    statement: Without Git, UIUX never invents Git revision information; with Git,
      Handoff may preserve its commit provenance.
  - id: 01a1144e-4f32-7d90-a59d-9f15462205d3
    statement: Installing `@deviltea/uiux` in the production repository is not
      required; the runtime is selected by the explicit Workspace path.
  - id: 01a1144e-4f4b-7ef3-b52e-4dfe9187adfe
    statement: Views, UX Flows, Review threads, Locales and authored Assets are
      separate canonical resources, each persisted as its own unit; the
      Workspace persisted format Contract gives their paths and the View shape.
  - id: 01a1144e-4f63-74af-a597-6d9689631960
    statement: "Grouping is a logical projection, never a storage layout: no
      grouping places, nests or moves a View file, and one View can serve any
      number of groupings and UX Flows without being duplicated."
  - id: 01a1144e-4f78-7a90-8d52-ace5cdd54dfa
    statement: Views, UX Flows, Review threads and authored Assets each have an
      immutable full UUID identity stored in the resource, and every reference
      to them uses that full UUID, never a file path, filename, display name,
      slug or shortened ID.
  - id: 01a114ec-85c3-7f30-b1f2-14e9fbbd8bd3
    statement: A Locale is identified by its canonical BCP 47 tag.
  - id: 01a1144e-4f8f-775d-b150-6ab107bb8129
    statement: A resource whose stored identity differs from the UUID in its file or
      directory name fails explicitly.
  - id: 01a11543-e3d8-72e2-b78c-dedff09e2c97
    statement: Two resources with the same identity fail explicitly, so copying a
      resource file never creates a new identity.
  - id: 01a1144e-4fa5-7ff4-aeb0-1278a85f188b
    statement: Display names and other human-readable labels can change without
      changing a resource's identity.
  - id: 01a11485-bb2c-7aba-a540-d762feff6573
    statement: A Workspace root may sit in a specification repository, a product
      repository or any ordinary directory; it need not be a Git repository root
      and is not coupled to a production repository.
