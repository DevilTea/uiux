title: Workspace layout and identity
summary: A self-contained, file-native Workspace directory, selected explicitly
  by the CLI, holds the `.uiux/workspace.json` manifest, one canonical JSON file
  per View, UX Flow, Review thread and locale, and one directory per authored
  Asset; every resource has an immutable UUID identity that matches its file or
  directory name.
