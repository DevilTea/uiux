---
id: 01a111e4-014f-73a1-8638-c3a58f134cf1
title: Adapter selection and resolution
summary: "Selecting, resolving, validating and installing a Workspace's
  Adapters: the ordered Adapter list, module resolution, identity and API
  compatibility, registry collisions, Adapter configuration and its delivery,
  the Product Kit stylesheet and theme root attributes, installation of
  providers, styles and design tokens in a Preview Runtime construction,
  invalid-set degradation and repair, the Adapter authoring entry, and the
  Workbench Adapter management surface."
rules:
  - id: 01a115cd-ab9b-720a-aa13-eda837160103
    statement: The ordered Adapter list is the only selection of active Adapters;
      UIUX never enables an Adapter by scanning dependencies or the filesystem.
  - id: 01a115cd-abd7-7af1-8358-c37218ed14f1
    statement: UIUX loads an Adapter only through its manifest, never by scanning
      package files, by filename conventions or through side-effect
      registration.
  - id: 01a115cd-ac0d-7a63-b694-791986652f65
    statement: Project-specific Widgets or Catalog metadata come from separately
      selected extension Adapters, never from forking or mutating a base Adapter
      while it runs.
  - id: 01a115cd-ac3e-7b8f-992d-323ae9eeb672
    statement: UIUX never installs, upgrades or locks Adapter packages and never
      edits package.json or lockfiles; it only reads resolved package metadata.
  - id: 01a115cd-ac6c-7f5b-90bb-825cd1ce2ce4
    statement: For a missing or incompatible Adapter package, the Workbench gives
      concrete package-manager repair guidance.
  - id: 01a115cd-ac9a-75c2-91df-4d8a0ccffcbd
    statement: UIUX checks an Adapter's declared API version for compatibility
      before using any of its plugins, Catalog, renderers, providers, styles or
      design tokens.
  - id: 01a11a5a-4aa0-7537-bbfc-600ea0ea61c5
    statement: UIUX refuses, as an incompatible API version, an Adapter whose
      declared API minor is above the highest minor its own release implements.
  - id: 01a11a5a-4b1f-7ebf-bd9f-e9156ae438d0
    statement: For an Adapter that declares a newer API minor than UIUX implements,
      the Workbench repair guidance is to upgrade UIUX to a release that
      implements that minor.
  - id: 01a11a5a-4ba0-745f-a297-bd8d33babded
    statement: An Adapter that uses a manifest member or entry field under a
      declared API minor below the one that introduced it is invalid; UIUX never
      loads it with that member ignored.
  - id: 01a115cd-acc9-7817-a65f-849e035f901d
    statement: An Adapter is identified by its declared ID, never by its package or
      display name; its resolved module and package version are provenance only.
  - id: 01a115cd-acf7-7b21-aff4-478e60281da9
    statement: Two Adapters claiming the same uniquely owned registry key is a
      blocking Adapter configuration error.
  - id: 01a115cd-ad26-7867-b3c0-de2392ac1ac7
    statement: Adapter order never grants first-wins or last-wins override
      authority; it only sequences otherwise valid installation of providers,
      styles and design tokens.
  - id: 01a115cd-ad53-7ab2-a241-3b3b34fa41aa
    statement: UIUX validates an Adapter entry's configuration against the
      configuration schema the Adapter declares, while the Adapter owns the
      schema's meaning.
  - id: 01a11a5a-515e-7c1d-9990-82e883c33243
    statement: Each provider of an Adapter receives in its install context a
      deep-frozen copy of exactly the configuration that passed validation for
      that Adapter entry, or `undefined` when the entry has none.
  - id: 01a11a5a-51dc-743c-993c-d4b3079beec7
    statement: UIUX gives Adapter code no configuration channel other than the
      provider install context; renderers reach configuration through their
      Adapter's own providers.
  - id: 01a11a5a-525a-75f4-b3be-62f02d5a5994
    statement: An Adapter's configuration never changes its Widget registries,
      Catalog or Widget plugin semantics; it affects only presentation and theme
      support.
  - id: 01a11a5a-52dd-7cb5-b12e-cef45b262a76
    statement: Changing an Adapter entry's configuration produces a new Preview
      bundle, and the next Preview Runtime construction uses the new value.
  - id: 01a11a5a-535f-73f2-96d0-6ccb02910f0b
    statement: "Adapter configuration is not secret: it is embedded in the Preview
      bundle, so anyone who can load that bundle can read it."
  - id: 01a115cd-ad81-78d3-bf85-cf711f00e170
    statement: An Adapter that declares no configuration schema accepts no
      Adapter-specific configuration.
  - id: 01a115cd-adb0-750e-a1f9-a254eb3fb25e
    statement: Design-System-specific configuration and data live only in the
      Product Kit file from `schemaVersion` 5, and below 5 only in the
      configuration of the manifest's Adapter entries; never in other fields of
      the Workspace schema.
  - id: 01a115cd-addf-7322-8ebd-f08952469905
    statement: UIUX resolves and validates the whole selected Adapter set, including
      resolution, API compatibility, configuration and collisions, before
      constructing a Preview Runtime.
  - id: 01a11a5a-4c2c-7330-8fac-11a6c970713a
    statement: UIUX checks the shape and ownership of every provider, style,
      design-token, theme-support and source-mapping entry during server-side
      Adapter resolution, so a malformed or foreign entry makes the Adapter
      invalid on every surface.
  - id: 01a11add-f633-74de-a5d0-d742ca55867b
    statement: UIUX reads an Adapter's source mappings only on the server, for
      Handoff, and never passes them into the Preview bundle.
  - id: 01a115cd-ae0e-7f4b-8fde-d3bd69751bce
    statement: "Only a fully valid Adapter set is installed: UIUX never skips a
      failed Adapter or builds a partial authoritative Runtime."
  - id: 01a115cd-ae3e-7ef7-8a53-5ccd86e143bf
    statement: A failure while constructing the Preview Runtime fails the whole
      construction and keeps no half-installed Runtime.
  - id: 01a11a5a-5059-716e-b0a5-d178395be034
    statement: A construction failed by the Product Kit stylesheet, or by a
      provider, style or design-token entry, reports the Preview as invalid with
      a diagnostic naming the stylesheet, or the Adapter, the member and the
      entry index.
  - id: 01a115cd-ae6b-7a85-be8e-0a42517daf17
    statement: An Adapter's renderers, providers, styles and design tokens are
      installed once per Preview Runtime construction, one mount of the
      validated Adapter set into a Preview document, and stay installed for that
      construction's lifetime.
  - id: 01a11a5a-4cb3-7d10-a39c-e40cc3120dc7
    statement: A fresh Widget Runtime for a Variant switch, or a live Locale,
      viewport or theme change, happens inside the current construction and
      reinstalls no provider, style or design token.
  - id: 01a11a5a-4d38-7f2c-98be-755d8c404d98
    statement: A construction links the Product Kit stylesheet, then installs every
      design token, then every style, then every provider, each in Adapter-list
      order and then entry order, before the first render.
  - id: 01a11a5a-4dbe-79e9-808e-6128ab510097
    statement: Adapter design-token and style elements are inserted into the Preview
      document's head after UIUX's own Preview stylesheets and the Product Kit
      stylesheet link.
  - id: 01a11a5a-4e44-77e0-bdf6-49ab11f5f3a5
    statement: UIUX removes the Product Kit stylesheet link and the design-token and
      style elements of a construction when that construction is disposed or
      fails.
  - id: 01a11add-f6b7-7676-9836-9a55c06c94eb
    statement: UIUX inserts the CSS text of `styles` and `tokens` entries as given,
      without parsing or rewriting it.
  - id: 01a11a5a-4ecd-7edb-a9e2-5918f01880e7
    statement: A provider installs synchronously; a provider whose install returns a
      promise fails the construction.
  - id: 01a11a5a-4f4c-782a-8d6c-17150999333e
    statement: Providers run only in the Preview document, never on the server.
  - id: 01a11a5a-4fd1-770d-8828-655638ef0d27
    statement: UIUX discards the Preview's Vue app, with everything its providers
      installed into it, when the construction is disposed.
  - id: 01a11a5a-50db-74a7-8933-059c1e36b07a
    statement: UIUX does not isolate Adapter CSS from its own Preview chrome; each
      Adapter scopes its CSS itself.
  - id: 01a115cd-ae9a-7bf9-bd40-8da4bcd669c1
    statement: A Workspace whose Adapter set is invalid stays open for inspection
      and repair, including Review, i18n and Adapter configuration editing.
  - id: 01a115cd-aeca-70ba-9b35-27de544863e5
    statement: While the Adapter set is invalid, Preview, render and capture,
      Catalog-dependent authoring and Adapter-dependent formal Evidence are
      unavailable.
  - id: 01a115cd-aef9-7b93-9619-96196f63cfde
    statement: UIUX never assembles a partial authoritative Catalog from the
      Adapters that did load, though it may show their safely readable manifest
      metadata for diagnosis.
  - id: 01a115cd-af27-798a-ab5b-3e5dfde30c93
    statement: A structurally valid Adapter list is written even when the Adapter
      set it selects is invalid; Adapter validity becomes Workspace diagnostic
      state, never a silent rollback.
  - id: 01a115cd-af57-781e-9493-89d037e41b06
    statement: The Workbench's Product Kit page manages Adapter selection, order and
      configuration and shows each Adapter's resolution, package, identity, API,
      configuration and collision diagnostics.
  - id: 01a11a5a-53e6-7292-a6a6-a45eae1e66d7
    statement: "The Adapter authoring entry follows the Adapter API version: a new
      minor only adds to it, and a breaking type change needs a new major
      version."
  - id: 01a11bb1-acdc-799f-aed7-c85ddbaf0d28
    statement: UIUX's Preview bundler builds the style entries, then the Adapter
      modules, into one JavaScript module and one stylesheet, including CSS
      imported anywhere in the module graph, with fonts and images emitted as
      files.
  - id: 01a11bb1-ad41-761c-ad47-a0e7ed5b8240
    statement: The first render waits until the Product Kit stylesheet has loaded.
  - id: 01a11bb1-ada4-7dd7-b3da-733de7a85df4
    statement: UIUX sets the active theme's root attributes from the Product Kit
      file on the Preview document element.
  - id: 01a11bb1-ae0b-7120-888f-97234df0aa3b
    statement: A live theme change swaps those root attributes within the current
      construction.
  - id: 01a11bb1-ae8c-721f-b1e4-f6936ffe5d5a
    statement: Preview bundles that `uiux dev` serves carry source maps.
  - id: 01a11be8-6078-7669-8e6d-6005d42c16dd
    statement: A Product Kit stylesheet that fails to load fails the construction.
