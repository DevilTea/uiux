---
id: 01a111e4-034a-7c44-ba0d-33d669c8b658
title: Workbench chrome language and theme
summary: "The Workbench chrome's own interface language and theme: the available
  languages, how the initial language and theme are chosen and changed, their
  independence from the Preview render context, and the zh-TW terminology
  policy."
rules:
  - id: 01a116f0-91f8-7cb9-a9d1-58b87c1c6ce0
    statement: The Workbench chrome is available in English (en-US) and Traditional
      Chinese (zh-TW).
  - id: 01a116f0-923f-7092-b759-3c7cc584e647
    statement: Until the user chooses a language, the chrome follows the browser's
      preferred languages and falls back to English.
  - id: 01a116f0-9282-7bf0-b48f-fe5bf0fcc0ac
    statement: The user can switch the chrome language at any time, and the choice
      is kept for that browser until the user returns to following the browser.
  - id: 01a116f0-92c6-7bca-8abf-1b7a375716c0
    statement: The chrome has its own light and dark themes and follows the
      operating system's preference until the user chooses one.
  - id: 01a116f0-930a-79a1-912c-f254ff9d8bd6
    statement: Changing the chrome language or theme never changes the previewed
      View's Locale or theme, and changing the render context never changes the
      chrome.
  - id: 01a116f0-934e-785e-b411-f6dd58be0f93
    statement: Workbench links never carry the chrome language or theme.
  - id: 01a116f0-9391-7304-b43c-0b96be55c4e4
    statement: In the zh-TW chrome, the glossary's domain nouns stay in English
      while actions and general interface text are translated.
  - id: 01a116f0-93d4-7787-a451-9613c16592f3
    statement: Chrome layouts tolerate the length differences between English and
      Chinese labels without overlapping or cutting off essential text.
---
