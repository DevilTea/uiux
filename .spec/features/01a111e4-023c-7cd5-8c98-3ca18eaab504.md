id: 01a111e4-023c-7cd5-8c98-3ca18eaab504
title: Widget navigation and highlight
summary: "Navigating to a Widget from Checks: structural selection, the
  Workbench-drawn highlight and how it tracks, hides and is restored,
  translucent-coverage notices, comment-mode deferral, and fallbacks for missing
  Views and Widgets."
rules:
  - id: 01a11658-1ac0-7478-946b-9872cc5d8f86
    statement: Navigating to a Widget from Checks opens its View and selects the
      Widget by its stable identity in the View structure, whether or not the
      Preview currently shows it.
  - id: 01a11658-1b0a-7841-be8f-6bbea49bd343
    statement: Navigation never switches the Variant, forces a hidden Widget
      visible, changes Widget State or rebuilds the runtime to show its target.
  - id: 01a11658-1b52-7f00-8f9d-eaf580c29253
    statement: When the target is rendered and visible but scrolled out of the
      Preview viewport, the Preview scrolls its own content to it before the
      Workbench highlights it.
  - id: 01a11658-1b97-7d59-94b2-e6f65abbbf56
    statement: When the target is not rendered, has no visible part or its
      visibility cannot be determined reliably, the Workbench keeps it selected,
      draws no highlight and shows that it cannot be highlighted in the current
      Preview.
  - id: 01a11658-1bda-7cf6-bf9d-a4373d40346b
    statement: A visible target's highlight follows the Widget's current geometry as
      it moves, resizes or reflows, updated by change events at most once per
      animation frame, never frozen or polled.
  - id: 01a11658-1c1e-70c5-855c-e73889c5e008
    statement: When the highlight's geometry becomes unavailable, stale or invalid,
      the Workbench hides the highlight at once and redraws it only from fresh,
      valid geometry for the current target and context.
  - id: 01a11658-1c60-7bee-b19c-1875fc53a564
    statement: The highlight covers only the reported visible part of the Widget,
      never a part clipped by the viewport or an ancestor or covered by an
      opaque element.
  - id: 01a11658-1ca4-79a0-ac41-9280810a02eb
    statement: When the visible part splits into disconnected regions, the Workbench
      outlines every region with its own complete contour, still as one selected
      Widget and one navigation.
  - id: 01a11658-1ce6-783a-86df-329abc0a3278
    statement: Fragmented or partly covered visibility never adds Checks findings,
      changes affected View or Widget counts or creates extra selections.
  - id: 01a11658-1d29-793c-9641-264dc477cfd5
    statement: When the target is still discernible under a translucent covering
      element, the Workbench shows one shared notice beside the highlight and a
      matching current-state marker on the Widget's Checks entry.
  - id: 01a11658-1d6e-75b1-b5c7-118341164ff5
    statement: The translucent notice and its Checks marker describe only the
      current Preview state, change or disappear with the target, context or
      coverage, and are hidden while comment mode suspends the highlight.
  - id: 01a11658-1db1-76ea-8cb5-8583b24bf6e4
    statement: Highlight stroke width is set in final Workbench pixels, so zooming
      or scaling the Preview never thickens or thins it.
  - id: 01a11658-1dfb-7723-bef9-352524844ea5
    statement: The Preview reports geometry and visibility only; highlight color,
      dash, opacity and glow come from Workbench design tokens.
  - id: 01a11658-1e40-75f5-baf5-25fd22b07c88
    statement: Entering comment mode hides the Checks highlight and stops tracking
      it, keeping the Widget selected and its target saved; comment targeting
      geometry keeps working.
  - id: 01a11658-1e85-74fd-aee2-f5048475992b
    statement: On leaving comment mode the Workbench restores the saved highlight
      only after revalidating its target and receiving fresh geometry, never
      reusing coordinates from before comment mode.
  - id: 01a11658-1eca-70be-b75f-a239dd6306dc
    statement: A Checks navigation requested during comment mode is queued instead
      of run, and a later request replaces the queued one.
  - id: 01a11658-1f0f-7b80-8e05-75a64d9f6ad6
    statement: On leaving comment mode, the queued navigation runs and takes
      precedence over restoring the earlier highlight.
  - id: 01a11658-1f54-7a9f-a168-c62e37ea6101
    statement: When a Checks navigation, immediate or queued, targets a Widget that
      no longer exists in a surviving View, the Workbench opens that View,
      selects no other Widget and draws no highlight.
  - id: 01a11658-1f97-7ea9-9715-e29d45ccb09d
    statement: A missing target Widget is reported by a persistent, non-modal inline
      notice in the navigation context until that context is replaced or left.
  - id: 01a11658-1fde-7b27-ba6d-6de27224b90c
    statement: When a Checks navigation targets a View that no longer exists, the
      Workbench stays on the current screen, keeps the selection and shows a
      non-blocking notice that navigation did not happen.
  - id: 01a11658-2022-757f-a7bc-e2b1944af01c
    statement: "A failed navigation is cleared: it never restores an earlier or
      comment-suspended highlight and never replays an older request."
