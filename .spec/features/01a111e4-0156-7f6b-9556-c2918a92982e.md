id: 01a111e4-0156-7f6b-9556-c2918a92982e
title: Adapter Catalog and Widget integration
summary: "The Adapter Catalog's authoring metadata for each Widget type: its
  boundary with Widget plugin definitions, i18n field mappings and their
  load-time validation, and asset-capable fields."
rules:
  - id: 01a115cd-af87-785a-a500-19bb8e3439d5
    statement: UIUX authoring metadata, such as labels, groups, icons, editor
      controls, i18n mappings and documentation hints, belongs to the Adapter
      Catalog and is never pushed into Widget Core.
  - id: 01a115cd-afb7-7713-8e3b-6887683add79
    statement: Only Config fields that the Catalog maps for i18n accept a
      translation binding; an ordinary string field is never translation-enabled
      implicitly.
  - id: 01a115cd-afe6-7e1f-9b61-805696ca3760
    statement: Declaring a translatable field needs no UIUX annotation in the
      plugin's Config schema and changes no raw Config type.
  - id: 01a115cd-b014-75c6-9e03-6a274d498a12
    statement: UIUX validates every Catalog i18n mapping when it loads the Adapter,
      and any mismatch invalidates the Adapter instead of producing a View
      warning.
  - id: 01a115cd-b046-76b8-ad6b-323fa69ebc60
    statement: An i18n mapping is accepted only when UIUX can passively prove from
      the plugin's own Config schema that the mapped Config field is
      string-only; any uncertainty is an Adapter load error.
  - id: 01a115cd-b078-7c39-874c-bf65da4fbb4b
    statement: Mapping validation compares declared Property metadata only and never
      evaluates a Property to infer its type.
  - id: 01a115cd-b0a7-7aff-97d0-2757ea9f510f
    statement: UIUX never executes, normalizes, dereferences, rewrites or duplicates
      a plugin's Config schema, and never treats Catalog metadata as the
      authority on Config types.
  - id: 01a115cd-b0d5-79c2-b533-b125964e0e7a
    statement: A Config schema that cannot prove a mapped field string-only stays
      valid for Widget Core; only the UIUX i18n mapping fails.
  - id: 01a115cd-b103-7db4-9a07-65badd12c50f
    statement: The Workbench locates translation-result Properties only through the
      Catalog mapping, never by Property name or by scanning values shaped like
      translation results.
  - id: 01a115cd-b132-71a6-aee2-c3406fbb5f54
    statement: An interpolation parameter maps only to a readable Property of the
      same Widget; expressions and cross-Widget lookups are not part of the
      mapping.
  - id: 01a115cd-b161-7550-b6e8-a2f694f591ee
    statement: A translation-result Property declares explicit reactive dependencies
      on the Properties its mapped parameters name.
---
