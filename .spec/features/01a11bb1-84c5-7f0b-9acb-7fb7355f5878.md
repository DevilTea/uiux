---
id: 01a11bb1-84c5-7f0b-9acb-7fb7355f5878
title: Product Kit
summary: "The Product Kit, the Workspace unit that holds a product's components:
  the external Design System packages it depends on, its one in-Workspace kit
  project of internal Design System components, product components and Adapter
  wrappers, its Workspace-owned data with the component registry and component
  table, and copying components out into product projects with drift reports."
rules:
  - id: 01a11bb1-a0be-7dee-b2e8-3686cef1aa17
    statement: A Workspace has exactly one kit project, which holds its internal
      Design System components, its product components and the wrapper entry
      that provides its Adapters.
  - id: 01a11bb1-a120-70a9-a875-3842da36c587
    statement: External Design System packages enter the Product Kit only as
      dependencies that the kit project declares.
  - id: 01a11bb1-a184-7e00-a8de-c81056ad5a35
    statement: UIUX shows kit project files, build output and the build log
      read-only; people and Agents change kit code directly, outside UIUX.
  - id: 01a11bb1-a1e5-70b6-a524-c1955425b1b2
    statement: The component table maps Widget types to components only for Handoff
      and browsing; the wrappers alone decide how a Widget renders.
  - id: 01a11bb1-a248-7fa3-9220-1cdf3e9a60b6
    statement: A Product Kit whose Adapters are plain modules in the kit project,
      with no build and no registry, is valid.
  - id: 01a11bb1-a2ac-754e-97c8-4f118218a051
    statement: "UIUX validates the registry on the server: every file a component
      declares exists under the kit's source directory and belongs to no wrapper
      entry."
  - id: 01a11bb1-a310-70a6-9f9b-c87ec2bcfaf9
    statement: A best-effort import scan flags each kit file that a component
      imports without declaring it in its closure, and each declared file that
      nothing in the component imports.
  - id: 01a11bb1-a376-719c-86e0-5f5e4d11cb8c
    statement: "`uiux components add` copies each named component and its `requires`
      closure into the target directory, keeping each file's path relative to
      the kit's source directory."
  - id: 01a11bb1-a3de-7426-94d2-c0e2bdd0be72
    statement: One copy record per product project covers every component copied
      into it, whatever its target directory; `uiux components add` writes or
      updates that record.
  - id: 01a11bb1-a444-7358-b030-69eb2ffbca9d
    statement: "`uiux components add` refuses to overwrite a copied file whose
      content differs from its recorded digest unless forced."
  - id: 01a11bb1-a4a6-7baf-8b27-e154f8e84356
    statement: Unless forced, `uiux components add` refuses, naming the recorded
      target directory, when a component it would copy, named or required, is
      already recorded at another target directory.
  - id: 01a11bb1-a50a-7a1c-b40c-8174708c1e31
    statement: "`uiux components add` writes nothing outside the copy record, its
      target directory and the target directories of components it moves."
  - id: 01a11bb1-a56c-7a63-9e5e-3ca8c7c4950c
    statement: UIUX writes into a product project only through `uiux components add`.
  - id: 01a11bb1-a5cf-7723-8b36-e6dc808381e1
    statement: UIUX keeps no record of copies inside the Workspace; the product
      project's copy record is the only one.
  - id: 01a11bb1-a630-7c7c-8dd3-5e0a11e4e919
    statement: "`uiux components diff` compares each recorded file's digest with its
      copy and with the current Workspace original, and reports one drift state
      per file."
  - id: 01a11bb1-a691-704d-b0bd-94fb59896ede
    statement: "`uiux components` commands act with the host user's file access and
      need no member credential."
  - id: 01a11be8-5931-7f80-a8e8-82bb1fced038
    statement: A forced `uiux components add` moves each component already recorded
      at another target directory, its copied files and its record entry, to the
      new target directory.
  - id: 01a11be8-59a6-71a1-a435-f6b707eb0940
    statement: After `uiux components add`, no component is copied twice in the
      product project and every relative import between copied components
      resolves.
