id: 01a111e4-015d-70aa-8098-a2bbe4690dc9
title: Locale resources
summary: "Authored Locale resources: Workspace ownership of copy, the global key
  space, the default Locale and a missing default-Locale file, the Review
  readiness policy for translation gaps, and empty or whitespace-only
  translation reminders."
rules:
  - id: 01a115cd-b192-79fc-90f0-f2b433001425
    statement: The Workspace's Locale files are the canonical source of authored
      copy and translations for the design specification.
  - id: 01a115cd-b1c1-786a-9758-b03aced4b157
    statement: UIUX works without a product repository or an external translation
      provider and never synchronizes Locale files with one.
  - id: 01a115cd-b1f1-7c39-9e3d-a8681847d8fa
    statement: All Locales share one global key space, and any View or Widget may
      reuse a key.
  - id: 01a115cd-b21f-7253-bc27-67628f18be27
    statement: UIUX never prescribes or validates a key-naming convention, prefix or
      namespace.
  - id: 01a115cd-b24f-7bcd-acd8-6b00d0aceff2
    statement: UIUX never infers the default Locale from file order, the current
      selection or which Locale files exist.
  - id: 01a115cd-b27e-79c7-a23d-f2ae3b387f1e
    statement: UIUX never creates a missing Locale file on its own.
  - id: 01a115cd-b2ad-7989-8faa-07d48bc8ee30
    statement: A default Locale without its Locale file is a persistent Workspace
      configuration error shown in Checks.
  - id: 01a115cd-b2dc-78a5-911b-a377bfcab278
    statement: While the default Locale's file is missing, the Workbench offers an
      explicit action to create it.
  - id: 01a115cd-b30b-706e-b8a2-46e62259156e
    statement: While the default Locale's file is missing, translation resolution,
      Locale-dependent Preview and capture, and formal translation Evidence are
      unavailable.
  - id: 01a115cd-b33a-7c3e-ba1f-bed8759b67d6
    statement: While the default Locale's file is missing, Workspace and non-i18n
      View authoring stay usable.
  - id: 01a115cd-b369-72f9-8291-1b9bd5dc04c2
    statement: Missing translations, fallback use, unresolved keys and missing
      interpolation arguments never by themselves block marking a Review ready,
      even for a translation Review.
  - id: 01a115cd-b398-7c3b-9d3b-66ac153bb3fc
    statement: Genuine Runtime failures, invalid Views or Variants, incomplete
      formal evaluation and blocking Workspace resource errors are never
      downgraded to translation warnings.
  - id: 01a115cd-b3c8-7eb7-9e04-c152d1f800cc
    statement: The translation summary flags every Locale value that is exactly
      empty, and every non-empty value that ECMAScript String.trim() empties, as
      two separate reminder categories.
  - id: 01a115cd-b3f8-7892-aa90-f121287ffdc6
    statement: Reminders cover every discovered Locale file and key, including keys
      that no View uses, without evaluating any Widget.
  - id: 01a115cd-b428-7f64-9c13-612ad4869d8d
    statement: The translation table marks each reminder on its Locale and key cell
      without changing the authored value or the Preview.
  - id: 01a115cd-b458-7def-a2eb-f1ec1395b99f
    statement: Empty and whitespace-only reminders never enter Review Evidence and
      never add a readiness gate.
  - id: 01a115cd-b48b-7b12-9a45-c325f84e39c6
    statement: Handoff carries no separate reminder list, count or issue report for
      empty or whitespace-only values.
