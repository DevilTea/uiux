title: Views list layouts
summary: "How Overview's Views tab shows Views as a list or as a grid of
  thumbnail cards: the layout choice and its persistence, card and row content,
  the placeholder and stale states, live replacement of an image and keyboard
  access."
rules:
  - id: 01a19b99-daf6-780f-a2ae-c96a4e27d37a
    statement: Overview's Views tab offers a list layout and a grid layout of the
      same filtered Views.
  - id: 01a19b99-db8e-7df7-b97e-5903af08a78b
    statement: The Views tab opens in the layout the member last chose in this
      browser, and in the list layout when none was chosen or the browser keeps
      no choice.
  - id: 01a19b99-dc1f-7f8c-86ed-d4f70b7e1533
    statement: In the grid layout a card shows its View's thumbnail, name, feature
      tag and readiness status.
  - id: 01a19b99-dcae-7cc7-9752-a309e7aef69a
    statement: In the list layout each row shows a small thumbnail before its View's name.
  - id: 01a19b99-dd5f-79bb-bfb6-d1446d6b6526
    statement: A card or row whose View has no thumbnail shows a placeholder, never
      a broken image or an error.
  - id: 01a19b99-ddf6-7460-88e7-55ad4aa5fbba
    statement: A card or row whose thumbnail is stale shows a stale indicator beside
      the image.
  - id: 01a19b99-de8d-7072-8399-915de730767c
    statement: A card or row whose View is refreshing shows that its thumbnail is
      being refreshed.
  - id: 01a19b99-df3d-7654-ab9f-253a58229524
    statement: When the server announces a changed thumbnail, the Views tab replaces
      that image in place, without a reload and without moving other cards.
  - id: 01a19b99-dfe8-7396-95d8-8e0cf1acf533
    statement: Opening the Views tab requests the thumbnails of the Views it lists.
  - id: 01a19b99-e07a-7e6c-a5ac-04e44e3ee035
    statement: A card is a link named by its View's name, and its thumbnail is
      decorative to assistive technology.
