---
id: 01a11c09-984a-7835-95ef-67164dd91746
title: Access presets
summary: "Named permission key sets that a Workspace keeps in its committed
  Access presets file: the built-in presets, editing and uniqueness, the labels
  derived from them for members, the Access presets page, how presets relate to
  the host-local roster, and how a key added by a new UIUX version reaches
  presets and members."
rules:
  - id: 01a11c09-c724-7a1b-9505-3146b5b2b241
    statement: "Access presets are Workspace data: they live in the Workspace's
      Access presets file and travel with it through ordinary commits."
  - id: 01a11c09-c78f-773d-ad98-5c6def1b22e3
    statement: "The built-in presets are only the initial content of the presets
      file: a Workspace may rename, edit, reorder or delete any of them, and may
      keep no preset at all."
  - id: 01a11c09-c7ff-72bb-8afe-2a7d1dc1024d
    statement: "No two presets have equal key sets: a write that would make two
      presets equal is refused."
  - id: 01a11c09-c86b-7526-a517-6220b027387a
    statement: A human member's label is the preset whose key set equals the
      member's keys.
  - id: 01a11c09-c8db-7236-87a1-5720487c486a
    statement: An Agent's label is the preset whose key set without its `humanOnly`
      keys equals the Agent's keys; when several match, the one with the fewest
      `humanOnly` keys wins, then the earliest in file order.
  - id: 01a11c09-c94c-77f1-b8e0-b9594584c193
    statement: A member whose keys match no preset is labeled Custom.
  - id: 01a11c09-c9be-736b-95a4-0b39d6f64cf0
    statement: The server computes labels whenever it answers and never stores them.
  - id: 01a11c09-ca2d-7b0e-b428-e2d66f5252dd
    statement: Editing, renaming or deleting a preset never changes any member's
      keys; only labels change, on every host.
  - id: 01a11c09-ca9b-7c86-9277-22b0397bee03
    statement: A preset holding a key unknown to the running UIUX version labels no
      member and is flagged on the Access presets page.
  - id: 01a11c09-cb08-7007-bcdd-8a04e54d02b5
    statement: A presets file that breaks a uniqueness or validity rule on disk, or
      is not JSON, for example after a Git merge, is reported with diagnostics.
  - id: 01a12f9c-3dab-7391-bef5-168f684187e7
    statement: A write naming the revision of a presets file that is not JSON
      replaces the whole file.
  - id: 01a11c33-265e-71f6-939f-4d0d3754a16f
    statement: While the presets file holds presets with equal key sets, labels use
      the first matching preset in file order.
  - id: 01a12f98-c032-7e1f-806c-41648565004c
    statement: "A `schemaVersion` 6 Workspace whose presets file is missing stays
      readable and writable, unlike one missing its Product Kit: presets only
      affect labels, while the Product Kit is required for rendering."
  - id: 01a12f98-d643-7e29-9273-23564146d518
    statement: "`update_access_presets` creates the presets file of a
      `schemaVersion` 6 Workspace that has none."
  - id: 01a11c09-cbea-7341-9d5a-01719e9c5d94
    statement: Access presets are read and changed over HTTP only; MCP offers no
      Tool or Resource for them.
  - id: 01a11c09-ccc6-705c-96c6-9f4ba7a2ad58
    statement: The CLI's `--preset <name>` resolves against the Workspace's presets
      at that moment and fails, naming the available presets, when none matches.
  - id: 01a11c09-cd38-72c0-9af6-4598454bdcfc
    statement: The Access presets page lists the presets in file order, each with
      its key count and the number of members on this host that it labels.
  - id: 01a11c09-cda4-748c-9e2e-5929c8447269
    statement: On a desktop layout a holder of `presets.manage` may add, rename,
      edit the keys of, reorder and delete presets on the Access presets page;
      for other members the page is read-only.
  - id: 01a11c09-ce14-7f47-bea9-9db3d283abf7
    statement: The Access presets page refuses an edit that would make two presets
      equal inline, before saving.
  - id: 01a11c09-ce86-702c-ae37-b284b4d818b4
    statement: After a preset edit, the Access presets page shows how many members
      on this host held the preset's old key set.
  - id: 01a11c33-2761-7fab-b0e5-c0f1863cb638
    statement: After a preset edit, the Access presets page offers a separate step,
      needing `members.manage`, that gives the edited preset's new keys to the
      members on this host who held its old key set; it never changes members on
      other hosts.
  - id: 01a11c09-cef3-7767-9d95-c3b89510aea3
    statement: The Workbench shows preset names as written and translates only Custom.
  - id: 01a11c09-cf7d-7ba5-bd8f-bfdeb12a8087
    statement: A key that a new UIUX version adds for a new capability is in no
      preset and held by no member until someone grants it explicitly.
  - id: 01a11c09-cff6-7b51-a85c-c9a26b78cba8
    statement: An existing operation moves to a new key only with a migration that
      grants the new key to every preset and member holding the key the
      operation needed before.
