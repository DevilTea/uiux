---
id: 01a11a5d-fd13-7f52-918c-af3a73e5bb6e
title: Version comparison
summary: "Comparing a version with its parent, another version or the current
  state: the per-resource summary, the semantic diff per resource kind, the
  structural fallback, comparison across schema versions, and the before/after
  rendering of a View on the canvas."
rules:
  - id: 01a11a5e-0d1c-7265-9058-72bef4da2b1a
    statement: A version can be compared with its parent, with any other version or
      with the current state.
  - id: 01a11a5e-0d72-7895-87e2-42f097ba41c9
    statement: Every comparison reports a per-resource summary, computed from the
      two sides' revisions, with the summary statuses that the Version history
      records Contract lists.
  - id: 01a11a5e-0ddc-7d9d-83b9-5366d0ac44dd
    statement: On request, a comparison reports a semantic diff per resource,
      computed on the server so that the Workbench and Agents get the same
      answer.
  - id: 01a11a5e-0e37-754b-bea2-a15716749c0c
    statement: A View's semantic diff matches Widgets by their stable ID and reports
      Widgets added, removed, moved to another parent, Slot or index, changed in
      type, or changed in config with the JSON pointers changed.
  - id: 01a11a5e-0e8d-7d8a-84f1-3195ac7719e7
    statement: A View's semantic diff shows `$i18n` and `$asset` bindings as
      references, not as resolved values.
  - id: 01a11a5e-0edf-7ea0-8d15-cc2a028d2a14
    statement: A View's semantic diff reports Variants added or removed, per-Widget
      State override changes, and changes of its name and `feature` tag.
  - id: 01a11a5e-0f31-7635-aeb2-16a1e9673b20
    statement: A View's semantic diff reports item-level changes per Spec section,
      and Decisions matched by ID with their status and outcome changes.
  - id: 01a11a5e-0f87-7bc0-b557-4f0b0b4886a3
    statement: A UX Flow's semantic diff reports steps matched by key, transition
      changes per step and entry step changes.
  - id: 01a11a5e-0fd9-7b50-a7c1-41a3091d9e0d
    statement: A Locale's semantic diff reports message keys added, removed or
      changed, and a Locale file added or removed.
  - id: 01a11a5e-102f-7caa-b63f-d7c6fb5189c0
    statement: A Workspace settings diff reports `i18n.defaultLocale`, viewports,
      themes and `adapters` by member.
  - id: 01a11a5e-1085-71ec-ac82-d60263ae8173
    statement: No comparison reports the manifest `schemaVersion`.
  - id: 01a11a5e-10df-795e-8fbc-a99de09694a5
    statement: An Asset's semantic diff reports metadata and content digest changes,
      with before and after images for image media types.
  - id: 01a11a5e-1134-755c-a740-a619a7943fe0
    statement: Where no semantic diff applies, a comparison falls back to a
      JSON-pointer structural diff, never a line diff.
  - id: 01a11a5e-118c-733d-92d7-27262bfbcd33
    statement: Both sides of a comparison are decoded under their recorded schema
      version, and an older side is first upgraded in memory with the migration
      steps, so a diff across a migration shows only design changes.
  - id: 01a11a5e-11e0-7f39-84a7-fde3faa43340
    statement: The Workbench shows a comparison's summary first, then the semantic
      diff per resource and, for a View, its canvas before and after.
  - id: 01a11a5e-1232-777c-a76d-26a6d5cbcfc0
    statement: The Workbench renders a historical View read-only in Preview, reading
      that version's manifest, View and Locales while the Widget runtime and
      Adapters are the current ones.
  - id: 01a11a5e-1288-7f86-a1cc-9b2fd0d2bd62
    statement: Side-by-side comparison shows two frames in the same Variant, Locale,
      viewport and theme.
  - id: 01a11a5e-12dc-793c-8f66-2d58c032fa19
    statement: Change highlighting outlines added, modified and moved Widgets on the
      after frame and removed Widgets on the before frame.
  - id: 01a11a5e-1331-7e9e-a98d-5ff9b265b0e8
    statement: Both frames use the canvas's current render-context selection; a
      Variant or key missing on one side renders that side's base state or
      default with a notice.
  - id: 01a11a5e-1385-7484-baf3-93d865fd97a5
    statement: A historical frame shows an Adapters-changed caveat when the
      version's recorded Adapter provenance differs from the current active set
      or is absent.
  - id: 01a11a5e-13d6-7a24-92e9-9a5de720ca27
    statement: Historical frames show no comment pins, muted or not.
  - id: 01a11e0d-d550-78e4-9787-f0023bbc1b93
    statement: A version's parent, for comparison, changed-resource summaries and
      the per-resource projection, is its predecessor on the merged timeline of
      host versions and Checkpoints, whichever store holds it; the stored parent
      pointers serve record integrity only.
  - id: 01a11e45-6bbc-7c95-9759-e42a3308e7a5
    statement: In side-by-side comparison, scrolling the outer stage scrolls both
      frames together, and scrolling inside one frame's content scrolls only
      that frame.
