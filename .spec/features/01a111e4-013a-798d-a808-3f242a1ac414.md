---
id: 01a111e4-013a-798d-a808-3f242a1ac414
title: View structure and RootShell
summary: A View is one canonical JSON resource whose Widget IR is rooted at the
  UIUX-managed RootShell Widget (reserved ID `root`) with exactly one `content`
  Slot of ordered child Widgets; UIUX validates only that reserved boundary and
  leaves the executable Widget IR to adapters, and an optional View-local
  `feature` tag groups Views for display.
rules:
  - id: 01a1144e-5129-79f4-bd12-6d871491265f
    statement: A View owns exactly one canonical Widget IR. Its Variants are initial
      Runtime State presets over that IR, not alternate Widget trees, snapshots
      or source patches.
  - id: 01a1144e-513d-7cf2-8e18-4a6f4494665b
    statement: The IR root is the UIUX-owned RootShell Widget plugin, persisted as
      the real root node with type `RootShell` and the reserved ID `root`, which
      ordinary Widget identity allocation never uses. UIUX creates it with the
      View, and no other Widget in the tree may be a RootShell.
  - id: 01a1144e-514f-7e38-be83-703ad352517c
    statement: RootShell has exactly one required Slot, `content`, holding 0..N
      ordered authored Widgets. An empty View has an empty `content` list;
      authors cannot add RootShell Slots, and a new system Slot needs a
      Workspace schema migration.
  - id: 01a1144e-5161-78b7-9360-710559d40c30
    statement: "RootShell presence, type, ID and Slot structure are system-managed:
      authors may change only RootShell fields that the schema marks
      user-editable, and deleting, retyping or re-identifying the root or
      breaking its Slot is invalid, even through a raw file edit."
  - id: 01a1144e-5174-7ea2-ab72-b5364dd48a03
    statement: The Workbench or Preview controller selects the render context
      (locale, theme, viewport and the selected Variant). RootShell exposes the
      effective values to descendant Widgets as read-only presentation context;
      neither descendant Widgets nor Variants can write it.
  - id: 01a1144e-5188-7a95-867c-d7e45487ebf8
    statement: View IR and Variant state may set only Widget State members that the
      plugin schema marks author-writable; computed, read-only or internal State
      stays non-writable, and a write outside that boundary is a validation
      error.
  - id: 01a1144e-519d-72c3-945e-f4cc657cf41f
    statement: Beyond the reserved RootShell boundary, the adapters' Widget plugin
      definitions own the executable IR semantics (types, schemas, defaults,
      Slots and Properties); UIUX keeps no second runtime schema for them.
  - id: 01a1144e-51af-72c6-ab79-9803d2cfa326
    statement: View IR describes view structure, component identity, states, copy
      and interaction rules; it never carries arbitrary business logic,
      networking or routing.
  - id: 01a1144e-51c3-72d2-a4be-822e8a9b23f5
    statement: Every View has a required human-readable `name`; changing it never
      changes the View's identity.
  - id: 01a1144e-51d6-7b17-8ef7-986d00f937e2
    statement: "A View may carry one optional `feature` tag, used only to group
      Views for display: untagged Views appear ungrouped, groups are derived
      from the current Views, and there is no persisted Feature entity, Feature
      directory, Feature lifecycle or link to an external Feature or scenario
      system. The tag is not part of Review anchor or UX Flow identity, and
      regrouping means changing the matching Views' tags."

## Implementation gaps

- 01a1144e-51c3-72d2-a4be-822e8a9b23f5: A View's `name` cannot be changed after `create_view` as of 17d4165: no MCP or HTTP operation edits it; tracked in issue #56 (https://github.com/DevilTea/uiux/issues/56).
- 01a1144e-51d6-7b17-8ef7-986d00f937e2: A View's `feature` tag cannot be changed after `create_view` as of 17d4165, so Views cannot be regrouped; tracked in issue #56 (https://github.com/DevilTea/uiux/issues/56).

## Notes

- As of 17d4165 no RootShell field is user-editable: the persisted RootShell carries only its type, ID and `content` Slot (`src/domain/views/schema.ts` L51).
