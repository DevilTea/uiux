---
id: 01a111e4-013a-798d-a808-3f242a1ac414
title: View structure and RootShell
summary: "The View as one canonical resource: its single Widget IR rooted at the
  UIUX-managed RootShell, the boundary between UIUX and Adapter-owned Widget
  semantics, the render context it receives, and its optional display-grouping
  `feature` tag."
rules:
  - id: 01a1144e-5129-79f4-bd12-6d871491265f
    statement: A View owns exactly one canonical Widget IR. Its Variants are initial
      Runtime State presets over that IR, not alternate Widget trees, snapshots
      or source patches.
  - id: 01a1144e-513d-7cf2-8e18-4a6f4494665b
    statement: Every View IR is rooted at the UIUX-owned RootShell Widget plugin.
      UIUX creates it together with the View, ordinary Widget identity
      allocation never uses its reserved ID, and no other Widget in the tree may
      be a RootShell.
  - id: 01a1144e-514f-7e38-be83-703ad352517c
    statement: Authors cannot add Slots to RootShell; adding a system Slot requires
      a Workspace schema migration.
  - id: 01a1144e-5161-78b7-9360-710559d40c30
    statement: "RootShell presence, type, ID and Slot structure are system-managed:
      authors may change only RootShell fields that the schema marks
      user-editable, and deleting, retyping or re-identifying the root or
      breaking its Slot is invalid, even through a raw file edit."
  - id: 01a1144e-5174-7ea2-ab72-b5364dd48a03
    statement: "The Workbench or Preview controller selects the render context: the
      Variant and, independently of it, the Locale, theme and viewport.
      RootShell exposes the effective values to descendant Widgets as read-only
      presentation context; neither descendant Widgets nor Variants can write
      it."
  - id: 01a1144e-5188-7a95-867c-d7e45487ebf8
    statement: View IR and Variant state may set only Widget State members that the
      plugin schema marks author-writable; computed, read-only or internal State
      stays non-writable, and a write outside that boundary is a validation
      error.
  - id: 01a1144e-519d-72c3-945e-f4cc657cf41f
    statement: Beyond the reserved RootShell boundary, the Adapters' Widget plugin
      definitions own the executable IR semantics (types, schemas, defaults,
      Slots and Properties); UIUX keeps no second runtime schema for them.
  - id: 01a1144e-51af-72c6-ab79-9803d2cfa326
    statement: View IR describes view structure, component identity, states, copy
      and interaction rules; it never carries arbitrary business logic,
      networking or routing.
  - id: 01a1144e-51d6-7b17-8ef7-986d00f937e2
    statement: "A View's optional `feature` tag is used only to group Views for
      display: untagged Views appear ungrouped, a View belongs to at most one
      group, and groups are derived from the current Views."
  - id: 01a11485-bbd5-70c1-ae04-cae536321fe7
    statement: "UIUX keeps no Feature entity for that grouping: no persisted Feature
      object or ID, Feature directory or Feature lifecycle, and no link from the
      tag to an external Feature or scenario system."
  - id: 01a11485-bbef-7485-80ed-791fe9b3bc5e
    statement: The `feature` tag is not part of Review anchor or UX Flow identity;
      renaming or changing a group means changing the matching Views' tags,
      never migrating an identity or moving files.

## Implementation gaps

- 01a11485-bbef-7485-80ed-791fe9b3bc5e: A View's `feature` tag cannot be changed after `create_view` as of 17d4165, so Views cannot be regrouped; tracked in issue #56 (https://github.com/DevilTea/uiux/issues/56).

## Notes

- The View `feature` tag is UIUX product data that groups Views for display in the Workbench; it is unrelated to the Features of this `.spec/` specification.
- As of 17d4165 no RootShell field is user-editable: the persisted RootShell carries only its type, ID and `content` Slot (`src/domain/views/schema.ts` L51).
- Calibration 2026-10-07: the former Rule `R.view.authoring.name` (import ref) was retired as a duplicate. The required `name` is owned by 01a1144e-53f4-7e66-b156-6ed7281f7f32, and changing it without changing the View's identity by 01a1144e-4fa5-7ff4-aeb0-1278a85f188b, which now carries its issue #56 gap.
