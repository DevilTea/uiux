title: Baseline request gates
summary: "The baseline request gates (Host, Origin, `Sec-Fetch-Site`,
  Content-Type and framing): which requests and origins each applies to, where
  they sit relative to authentication, and what each of them refuses."
rules:
  - id: 01a11485-edb2-77bb-9dc8-730c02deefb0
    statement: The baseline request gates (Host, Origin, `Sec-Fetch-Site`,
      Content-Type and framing) run first on every request, ahead of every
      handler including static assets; authentication runs after them, and
      authorization in the shared application layer.
  - id: 01a11485-edcc-75f5-ba60-ad152a59ab23
    statement: A request whose `Host` is not on the server's Host allowlist is
      refused before any handler runs; the Access Contract gives the allowlist.
  - id: 01a11485-ee00-76be-b967-5a2f1c1661b2
    statement: A state-changing request and every `/mcp` request are refused when
      they carry an `Origin` other than the origin that the request's `Host`
      matched, or a `Sec-Fetch-Site` outside the allowed values; the Access
      Contract defines state-changing methods and those values.
  - id: 01a114ec-e38f-78dd-9ba7-983b0f0e85bc
    statement: On every accepted origin, a request without an `Origin`, such as one
      from a script or an MCP client, is not refused for lacking it.
  - id: 01a11485-ee35-7e27-8a06-7b4a26628010
    statement: "A state-changing request that carries a body must declare
      `Content-Type: application/json`."
  - id: 01a11485-ee51-7ec6-a387-cd215d6cf161
    statement: UIUX never sends CORS headers.
  - id: 01a11485-ee6b-77ca-903d-34da460f2051
    statement: Every response forbids framing by other origins, while the Workbench
      can still frame its own same-origin Preview.
  - id: 01a11485-ee85-7844-b82f-fd6a7cebb763
    statement: The packaged server run directly, not through `uiux dev`, binds and
      accepts loopback only and serves no configured origin.
