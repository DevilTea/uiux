id: 01a111e4-0303-7dff-9ff5-c18101051308
title: Static publication
summary: "The read-only static publication of one Workspace that `uiux publish`
  builds: what it contains and leaves out, its independence from a server, its
  content identity and provenance, and where it can be hosted."
rules:
  - id: 01a11485-f262-7f14-a844-0899239eeeb9
    statement: "`uiux publish` builds a portable, read-only interactive site of one
      Workspace that needs no UIUX server, MCP or filesystem access at runtime:
      canonical resources, the Preview bundle and stylesheet, Assets, formal
      Evidence artifacts and the Handoff readiness assessment are captured at
      build time."
  - id: 01a11485-f27f-7224-a85f-989e56f91f41
    statement: Authoring controls are removed from the published site, while View
      context switching, Preview, the Inspector, UX Flows, Evidence inspection
      and readiness stay interactive.
  - id: 01a11485-f29e-7e71-a3b6-030a1dd80781
    statement: "The publication carries no Review threads: its Handoff readiness
      assessment may show aggregate Review counts (per resolution and
      unresolved) but no thread IDs or links to threads."
  - id: 01a11485-f2d9-7683-bea5-efb830bcf52f
    statement: Publication output carries a deterministic content identity and, when
      a source revision is given, that revision as provenance.
  - id: 01a11485-f2f5-7bff-830b-31298b3c35b9
    statement: The published site works under the URL path given as its base
      (default `/`), such as a GitHub Pages project subpath.
  - id: 01a11485-f312-7a04-a02c-d014558bcbb0
    statement: "Publication output contains no access data: no members, credentials
      or roster information."
  - id: 01a11485-f32e-7e9b-bafc-995a9f5f40bb
    statement: "Building a publication never creates or reads a host roster: the
      internal server it reads from keeps an empty in-memory roster and accepts
      only the run's own publish system credential."
  - id: 01a11a5e-1c4e-72d9-ad72-364a6549d779
    statement: "Publication output carries no version history: no Checkpoints,
      versions or diffs."
  - id: 01a11bb1-babc-7b56-967c-b76637278fe5
    statement: A publication contains no kit sources, registry component files,
      source maps or build logs.
---
