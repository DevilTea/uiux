---
id: 01a11bb1-8534-7f0f-b8d0-de7efabe31f7
title: Kit build
summary: "How UIUX runs the kit project's own build: when it runs under `uiux
  dev`, how its output is settled and consumed, its failures and timeouts, and
  what decides the process it runs."
rules:
  - id: 01a11bb1-9cb5-77f6-8e5d-5746bcfa9162
    statement: UIUX runs only the build that the kit project declares and consumes
      only its output; it never compiles kit sources itself.
  - id: 01a11bb1-9d17-7205-abee-c2aa7058c107
    statement: "Only host files decide what a build runs: no Workbench action, HTTP
      request or MCP Tool input supplies a build command or argument."
  - id: 01a11bb1-9d90-79c0-a51d-44382359bb6b
    statement: "Under `uiux dev`, UIUX runs one build process for the Workspace: the
      declared watch command, or else the build command once."
  - id: 01a11bb1-9df8-762d-b5e5-306f9898aae2
    statement: Each settled build output triggers a fresh server-side Adapter
      resolution and a new Preview bundle, so kit code edits reach the Preview
      without a server restart.
  - id: 01a11bb1-9e5e-79ab-841e-c953e8b44bbf
    statement: After a failed build, UIUX keeps using the last good output.
  - id: 01a11bb1-9ec6-7cc0-9bfe-9d3003c5d0b6
    statement: While no build output exists, the Product Kit is invalid and the
      Workspace degrades as it does for an invalid Adapter set.
  - id: 01a11bb1-9f2f-7559-b2ae-d61320f46627
    statement: Formal capture is refused while a build is running or after its last
      run failed.
  - id: 01a11bb1-9f91-7528-a71c-6cd206e25121
    statement: A build run that exceeds its timeout is stopped and fails; the
      timeout covers a build command run as a whole and a watch run until its
      first settled output.
  - id: 01a12f9d-a14e-70fe-b44a-cb8c7a85b899
    statement: A watch build becomes `ready` for the first time only after its
      output changes following the start of the build, so output left from
      before the start is never taken as its result.
  - id: 01a12f9a-f31e-704e-b93b-c93b33fd55d7
    statement: A restart requested while another restart is queued and not yet begun
      shares that queued restart's result instead of queuing another.
  - id: 01a11bb1-a05b-7686-beaa-22a90aa90fc2
    statement: "`uiux dev` prints a build's argument array before running it."
  - id: 01a11be8-6147-7e6e-a288-689144151a0b
    statement: While the last build run has failed, the Workbench shows a banner
      saying so.

## Notes

- Discussion #174 (Part 16) removed static publication: the Rules 01a11bb1-9ff8-7a58-a52e-8294e49882b9 (`uiux publish` runs the build once before its internal server) and 01a11be8-5fa2-796a-a896-7e602cc62d66 (a failed build fails `uiux publish`) are retired, and the summary and 01a11bb1-a05b-7686-beaa-22a90aa90fc2 name only `uiux dev`.
- Owner ruling 3 of 2026-10-12 (PR #197 review, https://github.com/DevilTea/uiux/discussions/139#discussioncomment-18878419) also has `uiux dev` print a warning once the kit build's output generations pass a threshold, since each generation imports the `./` Adapter module under a new URL that Node keeps for the life of the process. The threshold (50 as built) is non-normative, with code authoritative.
