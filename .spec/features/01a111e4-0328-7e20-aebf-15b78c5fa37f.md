title: Workbench information architecture
summary: Primary navigation is Overview, UX Flows and Reviews, in the desktop
  sidebar and the phone bottom bar; the View list is Overview's Views tab, and
  Workspace is one secondary entry with Settings (including Adapters), Locales
  and Assets sub-navigation. Reviews is a global inbox that hides resolved
  threads by default, lists `ready-for-review` before `open` and then latest
  activity first, shows Dismissed threads in their own tab, and deep-links to
  the exact View, Variant and render context; Prototype is a mode launched from
  a UX Flow. Owners reach Members from the member menu, and a command palette
  searches and jumps anywhere.
